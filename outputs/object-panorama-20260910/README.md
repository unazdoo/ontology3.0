# 对象全景六项调整：实施与实操验收

日期：2026-09-10。源码工作区 `prototype-composite-v1.3.0`，分支 `codex/prototype-v1.3.1-composite`。本轮按用户授权调整实现，没有用固定审查目录的旧快照作验收依据。

## 已落实

1. 对象发现取消右侧预览和普通浏览多选，表格/手机卡片保留名称、类型、地区/类别、关键指标、状态、风险事件、关联业务和截至日。
2. 画像地图与关系显示相关对象；银行可看其关联企业位置及真实融资借据，企业可看融资机构和部门。直接关系与经记录连接的路径分别说明，不补造地理位置。
3. 画像右侧问答支持对象基本信息、预算、风险事件、关联对象、持仓观测、进展及追问。会话按对象与源版本保留，答案附日期和依据。对象级加入报告功能移除。
4. 经营驾驶舱并入对象全景导航，保留集团、预算、风险经营内容；贷前与投资入口使用当前已纳入目录的业务对象和实际持仓信息。业务范围不是额外虚构的实体。
5. 对照先选查看目的，再挑对象；同一面板统一调整，取消不会改原结果。原对象、目录或业务范围都可发起，关闭后回到起点，刷新保留所选对象。
6. 事件区分本体规则、模型监控、业务事实。当前实际读取三条融资规则命中及正式债务风险模型预警；绿灯评分和普通办理日志不算事件。来源定位使用准确版本。

## 复跑与边界

独立启动服务和CDP浏览器后，从实施根目录运行：

```sh
BASE_URL=http://127.0.0.1:4524 CDP_URL=http://127.0.0.1:4526 OUTPUT_DIR=outputs/object-panorama-next node designs/prototype-work/v1.4/tests/object-panorama-browser.mjs
```

旧 `portrait-browser.mjs` 和 `direct-actions-browser.mjs` 入口转向当前业务回归，历史证据未覆写。

问答是当前已发布业务事实上的原型能力，不是通用大模型或收益预测。模型预警读取固定正式评估批次，未新增实时后台监听；候选与压力试算不混入正式风险事件。业务事实来源分类已区分，本轮未新增外部事件接入。地图使用已有城市级演示位置和省界，不含街道。预算归属公司4沿用既定演示映射。此前全机进程占用问题仍以专门报告的有限结论为准，本轮空闲数值不代表所有系统进程。
