# 经营态势与模拟数据快照

## 模块归属

融资与风险态势的主入口移到经营驾驶舱，原驾驶舱目录和五业务域保持不变。经营控制塔提供直接入口；首页入口从“探索与建模”移到“运营与智能”。M07只保留原通用对象发现与探索任务。

经营驾驶舱全部七个任务使用同一行横向导航；窄屏横向滚动并自动露出当前任务。态势模块移除独立的联合态势说明顶栏，观察日改放地图右下角，与图例和地图署名分开布局；原对象探索、问数、模型、已保存探索和来源操作收进现有工具栏的“更多”菜单。

问数、方案、事项、报告返回与来源血缘统一指向经营驾驶舱中的态势任务，不保留两套地图。旧 `#module/m07?task=situation` 形式的任务链接（实际查询参数位于hash之前）会迁移到 `?task=situation#dashboard`；旧“联合态势数据”任务链接回到原数据资产目录。

## Excel 与一致性

- 一份完整 `.xlsx` 文件，9张数据表，加“快照说明”和“字段字典”，共11张工作表。
- 300条记录全部导出，不以页面前20行或字段样例替代完整数据。
- 主键、外键、币种、金额单位、百分比和日期保留明确类型。百分比在Excel内部存储为小数，日期为日期值；每张明细表有筛选、冻结表头与主体ID列。
- 数据行从当前 `portfolio.json` 确定性生成，工作台与快照绑定同一数据指纹。字段字典与网页字段说明使用同一字段定义。
- 校验主键唯一、所有必填字段、数值和日期类型、跨资产外键；每项资产记录有独立SHA-256，完整文件另有SHA-256和字节长度。
- 文件在下载前重新读取并校验；HTTP失败或校验不一致不会触发下载，界面展示原因并允许重试。

## 交互闭环

地图框选作为独立筛选条件保存，不覆盖原问数或对象集范围。“取消框选”只移除地图条件，“显示全部企业”清除全部筛选并重新定位企业。空框选保留原范围；历史保存的空范围仍提供直接恢复入口。手机企业列表有明确关闭按钮，迟到的聚合查询结果不会在取消后重新应用。

数据资产目录 → 资产概览 → 字段与全部记录 → 查询/翻页 → 快照记录 → 下载完整Excel → 来源工作簿 → 相关资产血缘 → 经营态势。详情可刷新恢复，关闭回到目录。报告返回来源恢复到经营驾驶舱。

本地生成时间不等于数据观察日。快照观察日固定为2025-12-31；下载始终读取该快照文件，不将当前方案参数重新写入源文件。当前只提供已实际生成的一个快照版本，不捏造历史版本。
