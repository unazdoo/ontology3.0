# v1.4 实现复核

本轮已按用户要求改为在 v1.3.2 原平台上增量迭代。原独立地图应用不再作为平台入口；继承情况与新增能力归属以 `V13-INHERITANCE-REVIEW.md` 为准。下述计算与数据边界继续适用于联合态势模块。

## 本体优势如何落到交互

保留原有三域架构与首页交互，同时通过增量业务行为呈现本体价值：一个主体可在地图、借款、银行、担保、规则、问数、方案、事项和报告之间反复下探，身份不变；联合态势内部的消费者共用计算函数、对象集和结果身份。进入原业务工作区时保持企业主键，但不将合成融资数值替换为原有事实输入。

同时展示高成本、到期缺口与历史债务风险，但不把三者硬拼成一个“综合分”。例如历史红灯企业可以在当前融资演示窗口下没有资金缺口，这不是错误，也不能据此改写历史评分。

## 严谨性复核

| 风险点                         | 实现约束                                                   |
| ------------------------------ | ---------------------------------------------------------- |
| 企业别名被重复计数             | 统一企业主键，借款按唯一 Loan ID 汇总，所有外键校验        |
| 平均融资利率被简单平均         | Decimal 本金加权；三个来源主体与原总量和成本对账           |
| 混合币种、无效日期或缺失数值   | 拒绝无效数据；成本无分母时为缺失，不补零                   |
| 到期边界含糊                   | `asOf < maturityDate <= asOf + horizon`；窗口末日计入      |
| 把过期额度作为偿债能力         | 只计入有效至窗口末日的未用授信                             |
| 企业间现金相互抵销             | 先算逐企业缺口，再相加，不跨主体净额抵销                   |
| 借款、担保与未用授信重复相加   | 三类关系分开核算，银行敞口只汇总借款本金                   |
| 展期使已到期借款“复活”         | 仅投影观察日当期存续借款                                   |
| 模拟改写事实或正式评分         | 方案是独立副本；浮息、银行和企业范围明确，风险评分保持原值 |
| 130天被误识别为30天            | 完整解析窗口；展期天数与分析窗口分别解析                   |
| 未知主体或统计口径返回全体数据 | 未识别实体、跨期或币种口径拒绝；显式空集始终为空           |
| 历史答案引用当前方案           | 答案保存完整结果和方案；报告/事项使用该答案依据            |
| 删除方案使保存探索回到基准     | 探索保留固定方案，恢复时校验输入并重建原方案               |
| 报告复核后被修改               | 已复核版本只读；修订生成新ID和父版本，不覆盖历史           |
| 点击或跳页冒充业务执行         | 事项明确本地确认，记录真实状态变更；外部副作用始终为0      |
| 存储失败仍假装持久化           | 保留可用会话，给出持续的本地存储告警                       |

报告保留逐企业数值和借款快照；输入指纹、规则身份、版本与方案一并固定。参数作用后的借款快照明确标为方案结果，不重复应用模拟参数。

## 下探与界面复核

- 平台首屏恢复 v1.3 的三域架构和真实能力入口；地图放入原对象探索任务。同屏问数继续保留，不恢复含义不明的全局“当前上下文”选项卡。
- 当前范围、观察窗口和基准/方案状态就近显示；拖地图只改变相机，不暗中筛选数据。
- 聚合展开、列表点击、地图点击、框选、企业明细、关联对象返回均实际执行浏览器测试。
- 修复聚合点击在 `await` 后读取已失效地图事件的错误，提前复制聚合ID和坐标。
- 保存方案不重建地图实例，也不把参数面板归零；切换筛选后适配新企业集。
- 对象→借款→银行→相关企业可逐级返回。指标说明能查看实际取值和贡献借款，不只是公式说明。
- 关系网络有独立缩放、平移和复位；矩阵不会误操作隐藏的地图相机。
- 企业列表、调查面板、明细表、文档页和模态框各有明确滚动边界。手机使用可关闭面板，不缩成三栏。
- 工具采用图标及悬停名称，正文主要为14px；移除无法辨认的10/11px一般界面文案，保留紧凑标签。按钮、数字及导航按桌面和手机截图复查。

## v1.1 / v1.2 保留审视

复核依据包括 v1.3.2 的 `V11-PARITY-AUDIT.md`、`V12-PARITY-AUDIT.md` 和实际模块登记表。未将“旧模块文件还在”误写为“新工作台已重新实现全部能力”。

| 旧版好设计/需求                             | v1.4 处理                                                      |
| ------------------------------------------- | -------------------------------------------------------------- |
| 固定版本、来源和原结果回看                  | 新问数、方案、事项、报告及探索均保存固定依据                   |
| 保存探索、多视图、CSV                       | 新地图/关系/矩阵与保存恢复、撤销和CSV闭环                      |
| 连续对象下探                                | 主工作台原位调查，保留多级返回与滚动位置                       |
| 负责人待办和准确状态                        | 新事项含分办调整、进行中、完成、取消、重开和处理记录           |
| 报告草稿及冻结正文                          | 新本地草稿、复核冻结、修订和导出；历史正式正文保留在原报告中心 |
| 数据源/快照/管道/质量及本体 Draft/Published | 在原模块、原任务和原页面中完整继承；联合数据和规则仅为新增任务 |
| 问数设置、Agent资源与协作编排               | 原专业工作区保持可达，不用新固定意图解析器替代原配置能力       |
| 驾驶舱、模型目标、Python和候选观察          | 保留原驾驶舱入口；模型验证使用独立服务和原真实工作区           |
| 正式报告伴读、自动核验及丰富内容编排        | 保留原报告中心，不将本地复核草稿宣称为正式发布报告             |

各业务工作区均在继承的同一 Shell 内运行，不再通过“打开旧版”独立标签承接。联合报告能进入原内容块编辑器，保留编辑、排序、撤销和返回来源；原模块的数据与新增合成融资明细不自动互换。生产本体 SDK、通用页面构建、权限平台和外部金融执行不属于本轮原型实现。

## 验证证据与剩余边界

`tests/domain.test.mjs` 包含33项测试，覆盖计算、边界、身份、场景隔离、语义解析、状态、快照和安全转义。`tests/browser.mjs` 覆盖25条实际流程，包含1440×900、1280×720、390×844截图、WebGL像素检查、真实地图操作、下探、授信模拟明细、报告复核、恢复和失败重试。矩阵不绘制未登记依据的评分阈值线，风险分档直接引用原始评分结果。

联合态势专项结果在 `artifacts/verification/result.json`；继承平台集成结果在 `artifacts/inherited-platform/result.json`。原50个业务域/模块组合、36项UX、15项v1.1保留能力和90项滚动字号检查已重新执行，证据在 `composite/evidence/`。父版本文件校验纳入 `tests/inheritance.test.mjs`，历史目录没有被修改。

验证使用本机 Chrome，不等于实体手机、Safari、无障碍全审、多用户隔离、生产模型有效性或财务业务验收。MapLibre为主要包体来源，生产部署前仍需按网络与设备目标进行加载和帧率预算验证。`acceptanceReady=false`。
