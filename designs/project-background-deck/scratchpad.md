## 视觉系统

- 画布：1920×1080；固定缩放由最新 `deck-stage` 负责。
- Light Workbench：`#F4F5F6` 画布、`#FFFFFF` 数据面、`#111820` 正文、`#D7DCE1` 1px 分隔线、`#27313A` 导航框架。
- Dark System：`#090D10` 近黑背景、`#27313A` 轨道与面板线；仅用 `#2D72D2` 和 `#2F8F5B` 表示选择、通过和运行方向。
- 集团橙仅保留在现有品牌锁定图中，不进入大面积强调。
- 圆角：面板 0–4px；节点圆形只用于 Object 实例、连接端点和状态点。
- 不使用渐变、毛玻璃、发光、柔影、米色纸张或大圆角卡片。
- 字体：`-apple-system, "SF Pro Display", "SF Pro Text", "PingFang SC", "Noto Sans SC", sans-serif`；代码与资源标识使用 `SFMono-Regular`。
- 字号：标题 56px；封面标题 60px；主数字 78px；正文 27px；图形标签 24px；来源 20px。
- 内容安全区：左侧系统栏 76px；正文左右 112px；顶部 78px；底部来源区 54px。
- 页码、章节码、来源始终在同一基线；不使用英文眉题，标准资源名除外。

## 图形语法

- Object：白底方节点，1px 线，顶部 4px 类型色条；实例关系只用圆形端点。
- Link：1.5px 直线或正交线，箭头方向明确，线上直接写关系动词。
- Pipeline：编号轨道，节点按 01–05 排列；蓝色表示处理，绿色表示通过或采用。
- Version：平行轨道，不把数据、语义、报告和运行状态画成一个版本。
- Evidence：右侧窄栏或底部矩阵，列出文件/Sheet/口径/时间状态。
- Responsibility：Owner 写在节点顶栏，运行状态写在节点下栏，两者不得混用。

## 动效

- 仅在“数据—语义—消费—Action”链和 S001 轨道使用 `data-anim` 分步构建。
- 分步顺序解释因果：数据版本 → 语义绑定 → 结构化结果 → Action Request → 人工确认 → 待办。
- 其他样页无入场装饰动画；缩略图、打印和静态截图始终显示最终完整状态。
