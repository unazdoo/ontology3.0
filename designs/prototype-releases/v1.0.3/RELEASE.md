# 智财问策原型 v1.0.3 冻结基线

本目录保存 S001 v1.0.3 用户走查修订后的不可变、可运行原型副本。保留的精确历史场景轮次为：

`S001-RUN-20260814062516042-e1fd5e6ab3f4`

## 运行

从仓库根目录启动独立静态服务：

```bash
python3 -m http.server 4325 --directory designs/prototype-releases/v1.0.3
```

打开：

```text
http://127.0.0.1:4325/completed-run.html
```

点击“恢复并查看本次运行”后，页面先校验快照 SHA-256 和场景轮次，再恢复已经发生的 S001 历史浏览器记录。该动作不创建新的成功状态。

## 本版收口

- 平台品牌使用独立点阵神经网络脑形图标，并与本体管理图标区分。
- 本体已发布详情提供只读语义画布和数据沿袭视图；正式消费状态与上下文完整性分层呈现。
- 智能问数恢复权威语义资源读取并提供当前完整结果 CSV 导出。
- 决策工作台保留四笔待决策、一笔已处理和一笔追踪待办，已处理事项可回看。
- 仪表盘作为一级入口先进入目录，S001 详细仪表盘只调整排版。
- 六模块共享字号阶梯收敛，报告自动核验使用紧凑版本对照和可展开追溯。
- S001 版本化运行记录恢复后保持 `15/15`；`acceptanceReady=false`。

## 后续场景基线

v1.0.3 是 v1.0 系列后续真实场景开发的参考基线。可以复用平台外壳、模块入口、场景注册表、`scenarioId` 命名空间、跨模块上下文、只读状态投影、响应式布局和重置边界。

不得复制 S001 运行快照、业务成功状态、报告编号、待办编号或证据编号作为新场景状态。具体规则见 `SCENARIO-BASELINE.md`。

## 冻结规则

本目录不得原地修改。缺陷修复使用新的修订版本；新增场景从本基线复制到新的工作目录，并独立形成真实运行证据。

```bash

```

冻结只表示版本留档和后续开发参考基线，不表示六模块正式评审通过、S001 正式验收通过或一期验收通过。
