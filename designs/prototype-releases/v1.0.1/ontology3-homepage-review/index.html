Ontology 3.0首页方案评审
HOME · DESIGN REVIEW

三套首页，共用同一视觉语言

三版均延续旧平台的深色导航、灰白工作区、细描边卡片与蓝色交互反馈；差异集中在信息架构、密度和动效。所有状态均来自最新总控台账或采用中性表达。

方案 A

经典复刻版

最大程度保持旧首页的“左侧循环架构 + 右侧能力说明”，以三个能力域承载六模块。

布局最熟悉信息密度低动效克制
打开方案 A
方案 B

模块工作台版

把六模块入口、评审状态、待继续事项和当前工作放到首屏，适合日常回访与推进。

入口最直接信息密度高状态反馈明确
打开方案 B
方案 C

业务闭环版

以“数据—语义—决策—行动”组织首页，把六模块映射到平台主链与证据回流。

叙事最完整关系最清楚动效最强
打开方案 C
评审原型只展示首页入口、能力概览、设计状态与继续工作，不展开模块内部复杂功能。
