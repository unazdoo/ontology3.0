```bash
python3 -m http.server 4342 --bind 127.0.0.1 --directory designs/prototype-work/v1.1.0
```


## 统一业务闭环

适用场景按以下链路形成可追溯结果：

```text
数据接入与快照
→ 管道运行与数据资产发布
→ 本体映射、Published 发布与权威消费绑定
→ 智能问数与 Rule 结果（适用场景）
→ Action Request、人工确认与负责人待办（适用场景）
→ Agent 运行与固定依据
→ 报告生成、确定性核验与 HTML/PDF 发布
→ 报告伴读与自动核验
→ 管理驾驶舱分析与受控行动入口
```

“不适用”表示该场景在已确认业务边界内不经过对应模块，不作为链路缺口：S002 不进入决策中心；S004 不进入智能问数和决策中心。

## Owner 边界

- 数据工程拥有数据源、管道、资产版本、源快照和数据可信度状态。
- 本体管理拥有 Published 本体、Metric、Rule、Action Type 及权威消费绑定。
- 智能问数拥有问数配置、问数运行和回答结果；其配置只服务问数，不替代通用 Agent 管理。
- 决策中心拥有 Action Request 后续提醒、人工确认、待办和决策运行事实。
- Agent 应用拥有 Agent 配置、Session、Run、Result 和固定依据引用；不自行计算报告差异。
- 报告中心拥有报告定义、模板、报告生命周期、确定性核验和仪表盘定义/发布；仪表盘在产品中使用独立一级入口。
- 统一入口只负责导航和只读组合投影，不创建或改写各模块权威事实。
