本目录是 S004 的新纠偏运行版本：

> v1.0.3 六模块实际实现 + v1.1.0 场景运行时参数化 + S004 配置

固定身份：

```text
baselineVersion = v1.0.3
baselineSnapshotId = BSL-S001-V103-DE0119608E26
scenarioId = S004
scenarioVersion = S004-v2.1.0
```

它不覆盖 `scenarios/s004/` 当前 v2.0.1，也不修改 v1.0.3 发布目录、正式报告、历史 Checkpoint 或既有证据。

## 启动

从仓库根目录执行：

```bash
python3 -m http.server 4339 --directory designs
```

打开：

```text
http://127.0.0.1:4339/prototype-work/v1.1.0/scenarios/s004-runtime-v2.1.0/index.html#home
```

必须以 `designs` 为服务根目录，确保 v1.1.0 运行层和 `prototype-releases/v1.0.3` 处于同一 Origin。

- `index.html`：加载 Foundation、公共基线模块适配器、S004 配置和 v1.1.0 公共 Shell。
- `scenario-config.js`：仅提供 S004 场景配置和运行时数据投影。
- M01、M03、M04、M05、M06 直接解析 v1.0.3 冻结入口；M02 使用保留页面结构的已登记参数化入口，并以 v1.0.3 `review-v3/方案B2.html` 为原件。
- M04 冻结入口为 `prototype-releases/v1.0.3/decision-center-prototype/review-v2/action-portfolio.html`。
- `BASELINE-COMPATIBILITY.md`：基线入口和回归结果。
- `INTEGRATION-HANDOFF.md`：S001/S002/S003/S004 总装交接约束。
- `evidence/runtime-regression-20260816.json`：前序运行时回归证据。
- `evidence/runtime-regression-20260817.json`：本轮报告管理、报告生成和 Agent 详情整改回归证据；不属于正式 Checkpoint 或正式发布物。
