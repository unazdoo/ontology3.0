## 本次闭环

1. 从对象发现或驾驶舱选择对象，进入对象全貌、图谱、时序或对比。
2. 保存探索，或复制可独立打开的完整工作台链接。
3. 携带当前对象、对象集和结果模式进入模型、问数、解释或报告。
4. 将具体分析内容与来源写入草稿，编辑、排序、撤销、预览并导出。
5. 返回来源，恢复对象、筛选和视图。

融资、预算、债务风险、贷前、投后分别执行上述报告交付主线。原有数据构建、语义合同、Python 测试与运行、候选比较、三窗口 Shadow、复评、Release Candidate、Binding 和压力模拟继续保留。投后七阶段消费实际模块输出，不以页面跳转冒充完成。

## 验证入口

- `composite/tests/workflow.test.mjs`：数值类型、精确版本、对象范围、模式隔离、报告持久化及跨业务目标状态。
- `composite/tests/ux-regression.mjs`：独立临时服务，普通点击与键盘操作，1440×900、1280×720、390×844，五域报告往返、图谱缩放、链接恢复、编辑导出、错误恢复。
- `composite/tests/chrome-regression.mjs`：本版入口、50 个业务域/模块组合、原有推荐问题与行动链路、五域模型周期、Python 执行、投后七阶段、历史与刷新稳定性。
- `composite/evidence/ux/regression.json` 和 `composite/evidence/browser-regression.json`：最新机器验证结果。截图与导出样例位于对应 evidence 子目录。

## 边界

“闭环”指现有本地原型的功能与状态闭环，不代表生产系统上线。合成评测仍是示例数据；没有真实 NAV、现金流、费用、Outcome 等证据的指标继续显示缺失，不补造数据。模型预测与模拟仍不得直接触发真实放款、交易或通知。报告为待复核草稿，不伪装为已批准发布。

新功能使用 v1.3.2 独立本地存储键；继承的冻结业务模块仍沿用其既有场景 Foundation 合同。没有新增权限平台、审批层级、远程 Git 或生产基础设施。`acceptanceReady=false`。
