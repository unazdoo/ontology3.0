# v1.3.0-rc.1 实际变更清单

## 装配与 Shell

- 新建 `designs/prototype-work/v1.3.0/`，父版本 `v1.2.0-rc.1@e4974c23bd223f26bfd04b08dc6f46eb4d9ae5e0` 保持只读。
- 候选 Shell 选择性派生自 v1.2 `app.js`，直接引用父 Shell CSS；没有复制父目录或新建第二套 Shell。
- 首页删除“统一资源目录”、模块目录、全局场景切换器以及场景运行、进度和待办卡片，只保留平台能力架构。
- M01—M08 与 Dashboard 统一使用增强对比度的浅色 Shell 侧纵向二级任务导航，增大文字与点击区域；移动端为单一任务选择器。面包屑进入全局顶栏，独立目录行已删除，iframe 内重复菜单统一隐藏。

- 保留跨标签页不重载、`popstate/hashchange` 合并、旧 iframe 回调保护和深链恢复。

## 父版真实页面

- M01—M06 继续加载 v1.2 使用的真实本体、数据、智能问数、决策、Agent 和报告页面，不使用替代工作台。
- 删除 M02 顶部“债务风险模型数据资产”和 M01 顶部“债务风险模型语义合同”提示框。冻结 DataVersion 改为数据资产目录中的原生卡片或列表行，Semantic Contract 改为语义资产目录中的原生卡片。
- M02 将实际执行明细、预算下达明细、预算申报明细汇总和中国广核年度报告的不同年份文件归并为同一数据源下的 2/2/2/3 个快照；删除“选择业务范围”和“新建评测数据版本”。
- M02 已发布管道定义保持只读，版本菜单提供“新建草稿（可编辑副本）”；运行记录列宽、状态和操作区重新对齐。
- M01 已发布本体卡片不显示 S001—S005 场景编号，业务名称、正式版本和技术身份分层展示。
- 删除各模块的业务场景/业务范围选择器；数据、语义、对象和模型资源直接在各模块原生目录中统一组织。
- M03 保留父版 34 个推荐问题并新增 17 个模型结果问题，共 51 个；按“全部问题、融资成本、预算监督、债务风险、贷前评估、投后评价”六个页签筛选。
- S001 原“融资管理”的 4 个债务结构问题归入 S003 债务风险；页签切换改为原位显隐，不触发父页面主题状态、DOM 重建或 iframe 重载。
- M03 恢复父版五步处理动画：确认问题范围、读取权威数据、整理业务结果、核对回答依据、生成回答；每步约 680ms，并验证父版推荐问题和模型问题均保留动画。
- M03 新增过期运行取消，开始新会话后旧计时器不会回写迟到答案。
- “集团当前融资余额和平均融资成本”首答直接列出集团与六个产业板块成本及差值；BI 视图提供指标卡、横向柱状图、纵向柱状图和堆叠柱状图四种结构明显不同的可切换图形。
- “单位553的成本压力主要来自哪些银行”可发起醒目的行动申请，核对主体、银行顺序和 11 项固定证据后形成 C011 申请，并在决策工作台与运营驾驶舱持续跟踪。
- Shell 在切换模块前销毁旧 iframe 集成任务；问数延迟装饰任务纳入统一清理，消除离开问数后继续访问失效存储造成的卡顿和页面错误。
- M04 不再展示模型结果拦截、待我决策/已处理汇总卡或场景筛选；运营驾驶舱挂载在父 React 根之外，避免修改父 React 管理的 DOM。
- M05 模型解释能力进入真实 Agent 目录；M06 模型监测草稿进入真实报告目录并保持待复核。
- S005 取消 `module-workbench.html` 套壳路由，通过真实 M01—M08 页面驱动父版评价引擎。

## S003 数据与语义追溯

- M02 增加 6 类模型数据资产：企业纵向观察、独立结果标签、现金流、债务到期、关系网络、评级/诉讼/审计与重大事项事件。
- 每类资产显示粒度、行数、时点、可得时间、消费模型、缺失说明和从 synthetic recipe 到冻结 DataVersion 的血缘。
- M01 增加 10 个逐模型语义绑定，登记输入、输出、单位、时间粒度、空值策略、结果身份、DataVersion 和代码仓标识。
- Python 运行收据引用 DataVersion、Semantic Contract、质量结果、泄漏检查和不可变提交。

- M08 统一为“模型优化中心”，收敛为 5 个连续任务页：优化工作台、业务目标与模型、统一评测、候选观察、发布与监测；模型代码仓从模型详情下钻进入。
