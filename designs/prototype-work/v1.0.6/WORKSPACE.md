# 智财问策 v1.0.6 智能问数体验修订工作区

- 产品父版本：`v1.0.5`
- 唯一可编辑路径：`designs/prototype-work/v1.0.6/`
- 唯一工作入口：`s001-e2e-integration/index.html`

## 本轮范围

本工作区只承载 S001 智能问数工作台的体验修订：清爽问答首页、主题推荐问题、会话抽屉、新会话与清空、分阶段回答过程、回答详情、受控 BI 展示、明细和依据查看、CSV 导出及异常恢复。

结果详情继续消费同一轮固定结构化结果；图表、排序、Top N、图例和导出只改变呈现，不重查、不重算、不切换 T019 或数据版本。

## 版本与证据边界

- v1.0.5 的运行快照、15/15 记录和用户走查入口只读保留，用作回退参照，不作为 v1.0.6 证据。
- v1.0.6 当前为 `work-in-progress`，尚未形成新的运行轮次、快照、候选包或用户评审入口。
- `integrationResult=not-started`、`reviewEntry=false`、`acceptanceReady=false`。
- 不得将本工作区写成模块正式评审通过、S001 正式验收通过或一期验收通过。

## 禁止范围

- 不修改 v1.0.5、v1.0.3 冻结版本、v1.1.0 或 S002—S004。
- 不修改六模块主文档、平台总控台账、C008/C010/C017 等跨模块合同。
- 不把智能问数详情页扩展成通用 BI 编辑器；不维护报告中心仪表盘、决策提醒、确认、待办或执行状态。
- 不在页面常驻展示 Prompt、Skill、T019、C008、C017 或内部资源编号；技术证据仅在按需详情中显示。

## 启动方式

```bash
python3 -m http.server 4329 --directory designs/prototype-work/v1.0.6
```

打开 `http://127.0.0.1:4329/s001-e2e-integration/index.html` 进行工作区检查，或直接打开 M03 单模块预览路径。
