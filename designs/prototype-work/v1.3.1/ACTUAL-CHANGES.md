# v1.3.1-rc.1 实际变更清单

## 总装与 Shell

- 新建 `designs/prototype-work/v1.3.1/`，精确父版本为 `v1.3.0-rc.1@e3990c69e77882062035490ef718fd93549bbf82`；父目录、v1.2.0 和 v1.1.0 保持只读。
- 保留一套 v1.2 风格 Shell、主导航和左上品牌区；没有复制父目录或新建第二套 Shell。
- 首页保留三域架构，并恢复右侧真实功能入口。节点位置固定，域切换不触发 iframe 加载。
- 统一浅色纵向二级导航、顶部面包屑和移动端任务选择器；隐藏 iframe 内重复的模块级菜单。
- 新增 `WorkspaceContext`，在不重载页面的情况下同步对象集、当前对象、时间、对比、结果视图、数据版本、语义版本和证据。

## M01—M06

- M02 继续使用真实数据工程页面，将 10 个数据源、15 个来源快照、5 条管道和数据资产统一组织；跨年度文件保留为同一来源下的快照。
- M01 继续使用真实本体页面，以对象类型、关系、指标和下游使用组织已发布语义资产；卡片不展示 S001—S005 标签。
- M03 保留 51 个推荐问题、六个业务主题页签和五步回答动画；页签切换 iframe 重载为 0。
- 集团与产业融资成本首答、四类 BI 图形、单位553行动申请及进入 M04 的链路继续可操作。
- M04 决策工作台与决策运营驾驶舱保留总体流程、来源、运营关注和事项明细；非事实硬拒绝保持不变。
- M05 以任务入口组织解释能力；M06 可将当前工作上下文写入待复核报告草稿。

## M07 业务对象探索

- 从父版组合资源增量重构为本地 Object Explorer 与探索工作台。
- `#discover` 提供对象搜索、类型/质量筛选、多选、最近对象和已保存探索。
- `#explore` 提供对象目录、对象全貌、关系网络、时序分析、地图和对比分析六种 Lens。
- 56 个对象、49 条关系、39 个时序系列和 6 个事件共享同一对象身份与证据。
- 修复首次进入空白、默认对象误覆盖外部上下文和过滤结果被回灌为 56 个显式选择的问题。
- “继续分析”可携带对象、对象集、Lens、时间和版本进入问数、模型、报告或驾驶舱。

## M08 模型目标与优化

- 重构为目标目录、模型与代码、评测对比、候选观察、发布与消费五个任务页。
- S001—S005 的业务建模目标在同一目录展示；目标详情突出业务问题、输入输出、当前正式模型、最近候选、状态和下一步。
- 正式模型、Challenger 和补充模型分组展示；补充模型不进入综合总分。
- 评测固定两个版本和同一数据/语义/Evaluator，展示效果、校准、覆盖、漂移、业务切片和缺失原因。
- AI 洞察、人工审查、不可变候选、三段 Shadow、成熟标签复评、Release Candidate、Binding、消费者地图、压力模拟和回退串成完整循环。
- Python IDE、README、模型卡、测试、运行、分支、提交、标签和代码候选从模型详情下钻进入。

## Dashboard 与稳定性

- Dashboard 重构为经营控制塔，目录统一组织融资、预算、债务风险、贷前和投后五个驾驶舱。
- 目录不展示“模型结果”按钮；具体业务驾驶舱内提供“结果视图”，读取正式、候选、影子、模拟和差异结果。
- 业务视图切换不再重建 iframe；定向验证连续切换五个驾驶舱 frame load 增量为 0。
- 投后评价运行 ID 和五字段身份移入折叠证据，首屏只保留业务状态、覆盖、置信度与缺失原因。
- 1440×900、1280×720、390×844 采用独立信息层级；移动端对象表改为卡片，首页圆节点不再出现长英文裁切。

所有变更均位于 `designs/prototype-work/v1.3.1/`。
