## 一期范围

1. S003 风险工作台：风险总览、企业明细、企业报告穿透、配置状态和运行状态；
   M01—M06 均通过同一场景壳内的适配视图连续操作，不跳回早期独立原型。
2. M01 原子模型包：Published Metric、Rule、Action Type，包含公式、权重、评分锚点、
   调节因子系数和风险阈值；不新增一级“评分模型”资源。
3. M02 正式候选数据资产和企业因子在线填报，输入发布为不可变 T053 风格快照；
   不复用当前兼容性 T007，不在数据管道或质量规则中计算风险分。
4. M03 只读问数，消费同一 Published 风险事实。
5. M04 复用通用 Action Request、人工确认和负责人待办；不建设 S003 专属处置页面、
   多级审批或多用户权限。
6. M05 一期不建设 S003 专属 Agent，只登记“不需要专属 Agent”的模块导出。
7. M06 生成并查看每家企业的稳定深链报告，工作台显式发起受控重评。

## 用户确认的评分覆盖规则

- 在建企业财务原始得分固定为 `60`，仍叠加调节因子。
- 盈利历史不足时，盈利稳定性按 `A = 100`，记录
  `HISTORY_INSUFFICIENT_DEFAULT_A`。
- 因子适用但缺失时套用零系数档，记录 `DEFAULTED_ZERO`。
- 业务不适用记录 `NOT_APPLICABLE`，不得与缺失套零合并。
- 非法或越界值不是缺失，必须阻断发布或重评。
- `finalScore = round(clamp(rawScore × (1 + factorSum), 0, 100), 2)`。
- 风险分档：绿 `>=40`、黄 `[25,40)`、红 `[10,25)`、黑 `<10`。

## 目录语义

- `resources/`：M01—M06 的精确资源与合同导出。
- `fixtures/`：从权威工作簿形成的正式建设测试夹具；不等于兼容性 T007。
- `checkpoints/`：CP01—CP08 及高风险操作前快照。JSON 清单与其 SHA-256 是
  本包的正式快照证据，`localStorage` 只保存可丢弃的当前投影。
- `evidence/`：自动化测试、恢复/隔离和浏览器联调证据。
- `reports/`：报告清单和打印/导出约束。
