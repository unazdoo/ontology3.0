# S002 变更记录

## 2026-08-19 · 供应商服务人员人月成本比对口径修正（实施基准日仍为 2026-08-15）

- 将供应商复核范围限定为 `业务支持费-技术配置`，以预算申报“技术配置”成员中的年度预算净额和服务人月作为原子输入，不再使用单条报价、中位价或泛化供应商价格作为判定依据。
- 每条人月成本统一按 `年度预算净额（万元）×10000 ÷ 服务人月` 计算；比较组键固定为年度、预算二级科目、人员分类、供应商、人员级别、币种和税率，部门与项目只作为跨部门成员及穿透明细。
- RULE-005 改为比较同一供应商、同一级别、同口径组内各部门人月成本的最高/最低倍率；只有涉及两个及以上不同部门且倍率严格 `>1.2` 才显示异常，倍率等于 `1.2` 不命中。
- M06 供应商/人月成本专题增加组汇总和行内穿透，明细覆盖部门、项目、年度、净额、服务人月、人月成本、币种、税率、组内倍率和数据标识；净额、人月及维度字段保留 `SOURCE` 来源标识。
- 新增 `supplier-monthly-cost-comparison.test.cjs`，覆盖净额除以人月、比较组键、跨部门条件、严格阈值边界、M06 明细字段和 `SOURCE` 标识。
- 当前 S002 决策运行开关保持关闭；供应商异常不自动生成 Action Request、待办，不调用供应商系统或自动改价。
