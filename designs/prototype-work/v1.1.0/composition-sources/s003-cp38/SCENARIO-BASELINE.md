# v1.0 后续场景开发参考基线

## 基线身份

- 冻结版本：`v1.0.3`
- 基线场景：`S001`
- 基线入口：`completed-run.html`
- 基线状态：冻结、只读，`acceptanceReady=false`

## 可以复用

1. “智财问策”统一平台外壳和一级导航。
2. 首页、六模块及仪表盘的入口结构。
3. 场景注册表、`scenarioId` 命名空间和公共界面偏好边界。
4. 跨模块导航上下文、返回位置与滚动位置恢复。
5. 从模块状态只读投影首页摘要、链路进度、下一步和阻断的方法。
6. 当前场景重置、折叠菜单不重建 iframe、三档响应式布局和共享字号阶梯。
7. Action Request、人工确认、待办、报告、Agent 和当前数据比较的既有 Owner 边界。

## 不得复制

1. S001 的 `scenarioRunId`、浏览器运行快照或 `15/15` 完成状态。
2. S001 的数据版本、本体版本、问数 Run、行动申请、待办、报告、证据包和比较编号。
3. S001 的单位范围、指标结果、规则命中和银行建议。
4. 任一模块的 `localStorage` 或 `sessionStorage` 快照作为新场景初始化数据。

## 新场景接入步骤

1. 从本冻结目录复制业务代码到新的 `prototype-work/vX.Y.Z/`，不要在本目录修改。
2. 只登记已经确认的真实场景，不预置空壳场景。
3. 为新场景建立独立的 `scenarioId`、`scenarioVersion` 和新运行轮次。
4. 核对六模块合同是否携带并校验该场景身份；缺口登记 Owner，合同冲突提交 CR。
5. 从初始状态真实执行新场景流程，成功状态由用户操作产生。
6. 同时回归 S001，确认新场景状态不会污染既有场景。
7. 完成刷新、返回、模块往返、重置、失败恢复、三档尺寸和控制台回归后，再生成新版本清单。

## 结论边界

本文件只定义原型开发参考基线，不授予生产能力、模块评审或项目验收结论。
