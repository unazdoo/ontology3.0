# CP01 初始配置校验

形成时间：2026-08-15T12:48:25.000Z

## M01

- 模型资源类型为 Published Metric＋Rule＋Action Type 原子包，没有新增一级评分模型。
- 财务公司为业务 Owner；M01 拥有公式、权重、锚点、系数、阈值和 Published 生命周期。
- 已应用 D095：在建固定60、历史不足A、适用缺失0档、不适用单独标记、0—100夹取、黑档小于10。

## M02

- 仅定义数据源、管道、质量、正式候选数据资产和不可变人工输入快照。
- 明确禁止兼容性 T007 消费和原地晋升；风险计算参数不属于数据管道或质量规则。

## M03

- 仅定义 Published 风险事实只读查询；不得直接读取兼容性资产或自行重算。

## M04

- 仅复用通用 Action Request、人工确认和负责人待办；未建立 S003 专属处置页或多级审批。

## M05

- 一期明确无 S003 专属 Agent，模块导出为经 Owner 校验的“不需要”状态。

## M06

- 报告和风险工作台只读消费 C035；重评是显式操作，不自动创建待办。

## 恢复校验

- CP01 的数据、结果、报告、决策和测试夹具分区均显式为空，不存在不可定位状态。
- 所有非空状态均引用 S003 包内稳定文件并由 SHA-256 锁定。
- 恢复采用 `isolated-clone`，不得覆盖原轮次或重放历史外部副作用。
