## 一期范围

1. S003 风险工作台：风险总览、企业明细、企业报告穿透、配置状态和运行状态；
   `index.html` 仅兼容跳转至 `../../s001-e2e-integration/index.html?scenarioId=S003#home`。
   M01—M06 主入口继续加载 v1.0.3 基线模块页面，保留模块内部导航、工作区、画布、队列、
   对话和报告生命周期；S003 只注入场景身份、资源和条件式适配。
2. M01 原子模型包：Published Metric、Rule、Action Type，包含公式、权重、评分锚点、
   调节因子系数和风险阈值；不新增一级“评分模型”资源。
3. M01 模型配置只维护调节因子档位与系数、评分权重和风险分档，共用一个模型 Draft、
   校验和 Published 生命周期；不再设置“企业因子配置”页签。企业当期因子取值通过独立
   `T053` 人工输入快照随运行绑定，不进入模型 Draft，也不作为财务工作簿数据源或管道节点。
4. M03 只读问数，消费同一 Published 风险事实。
5. 黄灯、红灯、黑灯企业按亮灯结果逐户形成一条预警入口。集团债务风险管理人员在驾驶舱
   显式提交 Action Request 后，请求直接路由到对应成员单位债务风险接口人的通用决策中心；
   接口人确认后再分办负责人待办。M04 不建设 S003 专属处置页面、多级审批或多用户权限。
6. M05 一期不建设评分或处置专属 Agent；在基线 Agent 目录中为平台通用报告伴读 Agent
   条件式装入债务风险场景配置，且只能消费 Published 报告与证据。
7. M06 生成并查看每家企业的稳定深链报告；公共仪表盘可切换运行、提交行动申请并跳转 M01 统一模型配置，重跑仍由 C034 受控编排。

## 用户确认的评分覆盖规则

- 在建企业财务原始得分固定为 `60`，仍叠加调节因子。
- 盈利历史不足时，盈利稳定性按 `A = 100`，记录
  `HISTORY_INSUFFICIENT_DEFAULT_A`。
- 因子适用但缺失时套用零系数档，记录 `DEFAULTED_ZERO`。
- 业务不适用记录 `NOT_APPLICABLE`，不得与缺失套零合并。
- 非法或越界值不是缺失，必须阻断发布或重评。
- `finalScore = round(clamp(rawScore × (1 + factorSum), 0, 100), 2)`。
- 风险分档：绿 `>=40`、黄 `[25,40)`、红 `[10,25)`、黑 `<10`。


macOS 也可以双击工作区根目录的 `启动S003.command`。不要使用 `file://` 直接打开 HTML；场景资源通过 HTTP Fetch 读取，文件协议会被浏览器阻止。

## 目录语义

- `resources/`：M01—M06 的精确资源与合同导出。
- `fixtures/`：从权威工作簿形成的正式建设测试夹具；不等于兼容性 T007。
- `checkpoints/`：CP01—CP38 及高风险操作前快照。JSON 清单与其 SHA-256 是
  本包的正式快照证据，`localStorage` 只保存可丢弃的当前投影。
- `evidence/`：自动化测试、恢复/隔离和浏览器联调证据。
- `reports/`：报告清单和打印/导出约束。
