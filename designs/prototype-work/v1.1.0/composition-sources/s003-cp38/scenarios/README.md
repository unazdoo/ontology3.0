# v1.1.0 独立场景包边界

本目录只承载新增场景的独立实现包，不是统一总装入口。公共壳、`VERSION.json`、场景注册表、`foundation/`、S001 基线内容及六模块共享入口由 `codex/v1.1.0-base` 或 `codex/v1.1.0-integration` 维护。

| 场景 | 分支 | 独占可写包 | 端口 |
|---|---|---|---:|
| S002 | `codex/s002-v1.1.0` | `scenarios/s002/` | 4332 |
| S003 | `codex/s003-v1.1.0` | `scenarios/s003/` | 4333 |
| S004 | `codex/s004-v1.1.0` | `scenarios/s004/` | 4334 |

统一规则：

1. 场景分支只修改自身独占包；需要修改共享壳、公共资源合同适配、版本文件或 Foundation 时，提交变更建议给 base/integration，不在场景分支直接实现。
2. 每个场景包必须使用自身 `scenarioId`、`scenarioVersion` 和运行时新生成的 `scenarioRunId`，不得复制 S001 运行快照、成功状态或业务编号。
3. 场景包完成自身设计、正常/失败/恢复流程和隔离联调后，形成可审查交付包；不得自行写入统一总装入口。
4. 集成分支按 D093 顺序汇入 S002、S003、S004，每次汇入后回归 S001 和全部已汇入场景。
5. 本目录和 README 的存在只表示开发边界就绪，不表示任何场景功能已经实现或通过评审。
