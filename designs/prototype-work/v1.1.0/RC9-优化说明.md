# v1.1.0-rc.9 产品优化说明

当前状态为“已完成组装、待用户走查”，`acceptanceReady=false`。本轮不修改冻结版本、模块主文档、平台总控台账或原场景工作区。

## 首页与品牌

- 三个能力域不再旋转整组路径；数据治理、语义问数、行动智能只高亮自身关联路径和箭头。
- 架构图增加节点职责、当前关系和关系说明，选择语义问数时不会误亮对角路径。
- 智财问策图标增加两条沿边信号、24 个神经元分阶段闪烁和克制浮动；折叠菜单仍完整可见。
- `prefers-reduced-motion` 下停用浮动、信号和神经元闪烁。

## 报告中心

- 二级导航统一为上方横向导航栏，保留报告目录、创建与生成、报告定义三个工作区。
- 报告目录移除债务风险专属的“亮灯企业报告”，改为通用的“集团经营报告”等业务筛选。
- 报告问答只局部刷新右侧助手，不重建正文 iframe；回答过程按读取报告、定位证据、组织结论推进。
- 回答采用“结论、关键依据、证据状态、需要关注、使用边界”结构，并提供固定证据展开入口。
- 问答页只保留查看证据和清空会话，不放自动/重新核验按钮。
- 自动核验固定显示 5 组规则，检查单元按报告实际数量求和；每组可展开查看核验输入、方法、通过判据和本次结果。
- 核验运行按五阶段推进；S004 实测为 5 组、18/18 个检查单元。
- 移除与自动核验重复的“与当前数据比较”可见入口。
- “生成新内容版本”先确认定义、模板、对象、数据版本和说明，再直接创建 Agent 隔离运行并形成候选内容版本。
- 报告定义页提供“新增报告定义”，支持用途范围、模板生成合同、证据核验和发布门三段草稿配置。
- S004 受控 HTML 控制条与报告标题保持安全间距，不再遮挡标题。

## 债务风险驾驶舱

- 风险页面统一为风险总览、产业与薄弱项、风险处置行动、模型与运行四个页签。
- 产业分析只保留新能源产业、环保、核电三个产业；在建企业归属新能源产业，并单独作为建设阶段专题呈现。
- 风险处置行动只展示 5 条亮灯预警，不混入 21 家正常企业明细。
- 每条处置项展示识别依据、处置建议、行动类型、接收接口人、建议负责人和决策进展，并延续“查看依据→确认→提交 C011→决策中心跟踪”。
- 模型与运行只允许两类触发：新正式数据就绪后重评，或模型参数调整后校验、发布并重评。
- 模型修改流程收敛为暂存修改、放弃修改、校验/发布/重评一次完成；不再暴露难以区分的“仅发布”等按钮。
- 模型页不再重复展示企业正式报告明细表。

## 导航与边界

- 统一工作台为所有模块二、三级页增加“首页 / 模块 / 当前页”路径栏。
- 首页和模块层级可直接点击，当前页名称随 iframe 内路由、浏览器返回和刷新同步。
- 模型 Published 生命周期仍归本体管理；看板只提供受控业务操作入口。
- 风险确认只表示提交前核对，不能替代决策中心人工确认或直接创建待办。
- 报告问答只解释固定报告和证据，不重算业务数据或改写正式内容。

## 结论边界

本轮完成组合候选的功能实现和内部检查，不表示模块正式评审通过、场景正式验收通过或一期验收通过。用户明确通过前，`v1.1.0-rc.9` 不冻结为正式基线。
