# v1.1.0-rc.7 产品优化说明

本轮围绕四场景在同一产品内的资源一致性、功能闭环、交互可用性和业务可读性进行了集中优化。当前状态为“已完成组装、待用户走查”，`acceptanceReady=false`。

## 1. 数据工程

本轮将四场景数据统一装入一套数据源、管道和资产目录：

- 数据源目录现有 15 个已接入来源，状态、数据截至时间、场景用途和最近成功时间使用同一字段结构。
- 每个数据源都可进入详情并下载对应源快照，共 15 份。
- 数据源概览使用统一布局，完成态不再混入与当前业务无关的过程提示。
- 5 条已发布管道均可打开画布，节点、输入、输出、运行记录和关联资产可查看。
- 5 个已发布数据资产均可进入统一详情页，展示成员、版本、质量、消费状态和来源追溯。
- 债务风险场景的正式资产使用 `S003-T007-DEBT-RISK-20251231-v1`，与当前业务运行和下游引用保持一致。
- 已完成链路不再显示影响业务判断的错误或冲突状态。

走查建议：从任一数据源进入详情下载快照，再从关联管道打开画布，最后进入发布资产查看版本和质量。

## 2. 本体管理

本体目录和详情已按四场景统一：

- Published 页签显示 4 个本体，分别对应融资、预算、债务风险和贷前调查。
- 4 个本体均标记为当前正式使用，目录数量与实际内容一致。
- 每个本体均可进入详情查看 Published 版本、语义画布、数据映射、证据和消费关系。
- 每个本体都提供“创建修订草稿”，新草稿与当前正式版本分开，不改写已发布内容。
- 画布支持拖动、鼠标滚轮缩放和视图切换，操作方式保持一致。

走查建议：在 Published 目录逐一打开四个本体，验证画布操作、数据映射和创建修订草稿。

## 3. 智能问数

智能问数已补齐“语义资源—问数配置—会话—回答—证据”的业务闭环：

- 语义资源共 55 项：S001 37 项、S002 10 项、S003 8 项，均可从资源目录定位。
- 配置收敛为 1 个“智能问数助手”身份，S001、S002、S003 各保留一份精确 C009 领域绑定；场景、Published 本体、数据版本和资源白名单不会混用。
- S004 的贷前调查不进入通用问数，用户从报告伴读获取基于固定报告上下文的解释。
- 推荐区仅保留“全部、融资成本、债务风险、融资管理”四个页签，分别提供 34、10、12、12 个经过证据映射校验的问题；不再把报告伴读混入通用问数推荐。
- 工作台支持历史会话、新建会话、清空会话、五阶段处理中反馈和失败恢复。
- 回答首屏聚焦业务结论和必要说明；详细查询范围、BI 交互、CSV 导出和回答证据进入专门详情页。
- 语义资源顶部本体卡片只筛选下方目录，不再跳转本体管理；筛选结果和资源数量同步更新。
- 推荐问题覆盖指标、结构、单位比较、机构归因、预算监督和债务风险解释等可由当前事实回答的主题。
- S001、S002、S003 分别校验自己的场景轮次、已发布本体、数据或组合资产、质量和证据映射；不会借用另一场景的本地状态。
- 三个可问场景的新问题都先经历处理中再形成结果，并固定同一助手下唯一适用的领域绑定；CSV 导出会在导出前重新核对同一精确上下文。
- 问数配置只管理问数所需的提示词、Skill、白名单和语义绑定；通用 Agent 配置、会话和运行记录仍由 Agent 应用维护。

走查建议：分别选择融资、预算和债务风险推荐问题，查看生成过程、回答详情、BI 切换、CSV 导出和证据。

## 4. 报告中心

报告中心已改为统一报告目录和统一生命周期，不再先按场景进入不同页面：

- 报告目录集中展示 24 份正式报告：S001 1 份、S002 1 份、S003 21 份、S004 1 份。
- 目录顶部使用“全部正式报告、需要复核、风险企业报告、本月发布”四个可点击业务筛选，报告类型和期间继续作为筛选条件；列表、卡片、详情和操作保持同一结构。
- 正式报告统一使用贷前调查成熟版的三栏阅读工作台：左侧章节目录、中间正式 HTML 长正文、右侧报告助手与自动核验；版本、比较、证据和详情从同一工作台进入。
- 报告定义共 4 套，每套绑定唯一当前模板、证据范围、报告 Agent 和确定性核验规则。
- 每个模板都可在线查看和下载，模板章节与对应正式报告结构一致。
- 创建报告按“选择定义—确认模板—绑定对象与数据—核对并生成”的顺序执行；未选择定义和模板时不会进入生成。
- 生成完成后形成待复核草稿，确认后再进入正式发布，历史正式版本保持不变。
- S004 正式内容 2.0.0 与候选内容 2.1.0 分开管理，不覆盖历史产物。
- 24 份正式报告均具备实际 HTML 与同源 PDF；风险报告使用业务报告编号，贷前报告不再带评审水印或内部说明。
- 报告伴读和报告生成都会先在 Agent 应用形成 Session、Run、Result 与回执；报告中心只在回读成功后展示回答、草稿或新正式版本。
- 正式报告“内容”页直接展示真实报告正文，不再用章节占位句代替报告内容。
- 章节目录从实际正式 HTML 解析，四类报告共 25 个章节入口均可准确定位；切换报告和功能页时滚动位置按页面隔离并回到合理起点。
- 报告助手提供与当前报告绑定的推荐问题，具备三阶段处理动画、失败、重试和清空会话状态；自动/重新核验具备独立运行过程、折叠详情和结果，且不与报告问答重复维护证据真值。
- “查看证据”在通用和 S003 阅读器中统一打开同一证据入口；内部抽屉以业务可读方式解释报告内容、固定证据包、语义和数据版本之间的关系。
- 正式报告在窄屏下保持正文纵向阅读，宽表只在表格内部横向滚动；桌面 A4 排版和打印输出不受移动端规则影响。
- 报告中心菜单不再重复放置仪表盘入口。

走查建议：先在报告目录查看四类正式报告，再从报告定义下载模板，最后完整执行一次创建与生成流程。

## 5. 仪表盘

仪表盘使用独立一级入口，统一承载三个管理驾驶舱：

- 集团融资驾驶舱保留经营概览、单位比较、结构与机构、规则与行动 4 个原场景视图。
- 预算管理驾驶舱保留成本与预算、项目余额、费用与差旅、跨年计提、年末占用、供应商价格 6 个原场景专题。
- 债务风险监测驾驶舱保留风险总览、产业下钻和 21 家企业明细，支持风险分档、产业、关键字与排序组合筛选，并可穿透企业正式报告。
- 债务风险监测驾驶舱使用四个页签：风险总览、产业与薄弱项、企业明细与行动、模型与运行。模型配置为本体管理 Published 只读投影；运行使用正式资产 `S003-T007-DEBT-RISK-20251231-v1` 创建新的隔离轮次，历史运行不覆盖。
- 三个驾驶舱使用统一目录、页头、筛选、图表、下钻和行动摘要结构。
- 融资指标只展示本期正式结果，不再显示无连续历史依据的环比、趋势箭头或趋势图；预算趋势只保留来源资料支持的跨年序列。
- 图表切换、筛选和视图保存具备即时反馈，指标、结构和比较信息保持同一业务上下文。
- 融资驾驶舱按一笔执行中、两笔待人工确认展示决策摘要；预算监督发现保持业务跟踪语义，不进入决策中心。
- 适用场景的行动状态只读引用决策中心；查看或下钻不会在仪表盘内维护确认和待办。
- 报告创建回到报告中心执行，并明确选择报告定义和模板，避免驾驶舱与报告生命周期职责混杂。

走查建议：依次进入三个驾驶舱，切换图表和筛选，查看专题、单位或企业下钻以及行动详情。

## 6. Agent 应用

Agent 配置、运行和结果已与四场景链路对齐：

- 目录共 8 个 Agent，覆盖适用场景的洞察、报告生成和报告伴读职责；问数助手配置明确留在智能问数，不在 Agent 应用重复维护。
- 运行目录有 8 条完成 Run/Result，并可回到对应 Agent、场景、输入和输出。
- 固定依据共 4 个，分别关联精确数据、Published 本体、报告或决策上下文。
- 报告伴读共 3 个 Session，使用报告编号、内容版本和证据包定位固定上下文。
- 用户从报告中心新增伴读或报告生成请求时，Agent 应用会形成新的处理记录、结果和回执，并支持失败后以新尝试重试。
- Agent 目录只保留“可用 Agent / 配置草稿”两项有效摘要，重新进入模块时稳定返回目录，不再恢复到报告伴读详情。
- Prompt、Skill、Tool 详情补充角色、前置核对、证据使用、输出结构、失败规则和运行时工作原理，可直接支撑后续实现。
- 证据与结果页用一条业务链解释固定依据、Agent 结果、工具轨迹和下游回执，回答“本次运行依据什么、形成什么、怎样形成、交付到哪里”。
- Agent 不自行计算报告差异、不维护数据质量真值，也不替代问数配置或决策中心状态。

走查建议：从 Agent 目录进入配置，再沿 Run 查看 Result、固定依据和下游报告或决策回执。

## 7. 整体体验与产品闭环

- 首页、M01—M06 和仪表盘保持同一产品导航，不使用场景切换壳或独立场景页面。
- 一级导航负责模块切换，模块内功能使用横向导航，已消除重复侧栏。
- 四场景使用各自精确 `scenarioId`、`scenarioVersion` 和 `scenarioRunId`，筛选或返回不会覆盖其他场景状态。
- S001、S003 为六模块完整链路；S002 不进入决策中心；S004 不进入智能问数和决策中心，适用边界在界面和运行账本中一致。
- 页面按钮、页签、筛选、详情、返回、下载和关键流程已执行功能回归。
- `1440×900`、`1280×720`、`390×844` 已完成可读性、长页滚动和横向溢出检查；报告正文、报告目录、六个预算专题和风险企业明细均可滚动。
- 首页、六模块和仪表盘入口均可访问，控制台新增 error 为 0。
- 五条数据管道的生产画布均绑定各自成功运行、精确输入、数据资产和正式采用状态；不存在跨场景状态串线。
- 总装级自动检查覆盖四场景身份、七个一级工作台、24 份 HTML/PDF、报告号和跨模块关键数值。
- 本轮进一步收敛：本体资产目录单击直达当前版本详情；智能问数采用一助手三绑定和 34 个精选问题；决策中心以“追踪待办”为唯一运营入口，AI 摘要按当前申请、Rule、证据、负责人和期限生成；Agent 配置资源与证据链补齐实现级说明；报告目录与三栏阅读器按 S004 最新设计对齐；三套驾驶舱完整保留各场景支线能力并清除无来源展示。

## 走查结论边界

本轮完成的是四场景组合产品的组装与内部检查。用户走查前保持 `acceptanceReady=false`；当前状态不表示模块正式评审通过、场景正式验收通过或一期验收通过。
