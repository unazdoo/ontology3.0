# v1.1.0 后续场景工作区

本目录仍是从旧版建立、尚未开展场景建设的历史工作副本。当前权威参考基线已更新为冻结 `v1.0.3`；开始任何新场景修改前，必须先从该冻结目录重新建立工作副本，不得直接在旧业务文件上继续开发：

`designs/prototype-releases/v1.0.3/`

## 当前状态

`rebase-pending`。重建完成前，本目录不作为可运行的新场景开发入口。

## 重建后启动

```bash
python3 -m http.server 4321 --directory designs/prototype-work/v1.1.0
```

入口：

```text
http://127.0.0.1:4321/s001-e2e-integration/
```

端口不得与冻结版共用，避免浏览器状态相互污染。

## 开发规则

1. 新场景必须拥有稳定 `scenarioId`、`scenarioVersion` 和运行轮次。
2. 新场景数据与状态进入场景命名空间，不改写 S001 已有事实。
3. 模块变更先写入 `CHANGELOG.md`；涉及合同冲突时登记 CR。
4. 发布前同时回归 S001 和新增场景，不以新增场景成功替代 S001 回归。
5. 候选版不得覆盖 `v1.0.3`；通过后冻结为新的版本目录。
