# 地图名称与本体内规则管理

## 地图标签

单企业点位显示“企业名称（所在市）”，选中标签使用同样格式。密集点位仍采用聚合数量，放大后展开企业；标签继续使用地图引擎的避让能力，选中企业通过浮签完整显示，避免重复标签。

## 规则归属

取消M01“融资规则验证”独立页签和工作台中的独立规则编辑页，不再维护第二套规则输入入口。

- `ONT-GROUP-FINANCING-OPTIMIZATION`：融资成本偏离预警，以及余额、加权成本、银行敞口和成本偏离定义。
- `ONT-S003-DEBT-RISK`：偿债资金缺口预警，以及窗口到期、资金缺口和历史评分引用定义。

以上内容以原生本体修订草稿加入原 `state.drafts`，保留 `ontologyStableId`、`basedOnVersionId`、规则ID和Metric依赖。原已发布规则不被覆盖，特别是不将“相对产业基准”的模拟规则替换为原来“相对集团基准/高成本余额占比”的已发布规则。

本体模块使用轻量本地入口装配新增草稿，编辑器JS、样式和原种子继续复用冻结版本，不复制或改写原编辑器实现。新增草稿仅初始化一次；用户修改后刷新不会被重新填回默认值。迁移前独立验证记录保留在融资本体修订的验证记录中，同一数据版本的最近阈值作为初始规则条件。

## 操作闭环

语义资产 → 对应本体“规则与指标修订” → 规则资源 → 原生“编辑配置” → 保存 → 规则验证 → 在经营态势查看 → 问数/报告。

验证读取当前原生规则条件和指标定义。条件或指标不受当前确定性验证器支持时明确阻断，不套用旧阈值。验证固定本体、来源版本、草稿、规则内容、数据指纹、观察窗口和对象范围；返回驾驶舱、问数和报告继续保存这些身份。定义发生变化后旧结果不能直接应用。

当前验证使用完整模拟快照。草稿仍需走原本体的映射、统一校验与发布流程，不因模拟验证通过就宣称正式发布、正式采用或风险评分已更新。新增源属性与正式映射尚未建立的内容保持待校验，不写入原正式规则或模型。
