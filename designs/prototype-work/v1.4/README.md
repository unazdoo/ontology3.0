# 智财问策 v1.4

在 v1.3.2 原型基础上增量迭代。原首页、品牌、三域架构、M01-M08、五业务域、驾驶舱、资源目录、页面内容和操作流程均继承。全球地图与同屏问数归入“经营驾驶舱 → 融资与风险态势”；M07迭代为业务全景，以当前情况、判断依据、关联业务、行动及办理结果为主线。详细操作见 [M07 业务全景使用说明](M07-BUSINESS-GUIDE.md)。

上一轮独立地图平台方案已取消作为主入口；各专业能力不再通过“打开旧版”链接承接。

## 企业业务对象与预算

M07目录包含企业、金融产品和产品汇总持仓，提供通用预览、完整画像与多对象列表/平铺/时序/比较。公司4作为预算演示归属企业，部门、年度预算和科目期间明细从企业下钻；持仓按现有台账范围内的产品汇总。集团总览与临时投资组合采用视图或对象集。

M07固定读取M01实际校验并发布的V2定义及源投影，所有实例有精确类型、身份和关系绑定；原融资正式V1及已有审批/报告不被替换。来源投影可以在原数据工程目录查看与下载。详见 [使用说明](M07-BUSINESS-GUIDE.md)。

## 运行

需要 Node.js 22，以及支持 WebGL 的现代浏览器。

```sh
npm ci
npm run dev
```

默认入口 `http://127.0.0.1:4394`，配套静态服务 `4392`，独立模型服务 `4393`。不会重置原 `4382/4383` 预览服务。端口占用时可改用：

```sh
PORT=4404 STATIC_PORT=4402 MODEL_PORT=4403 npm run dev
```

主入口自动进入 `composite/s001-e2e-integration/index.html#home`。态势入口为“经营驾驶舱 → 融资与风险态势”，首页“运营与智能”和经营控制塔也可直接进入。原M07态势深链自动迁移。

`npm run build` 编译入口和联合态势模块；平台沿用既有静态资源及模型服务，不是可直接双击的独立 HTML 包。`workbench.html` 仅为嵌入模块及专项测试入口，不作为用户主平台。

## 已实现

- MapLibre 全球球面投影，平滑滚轮缩放、拖动、聚合展开、框选、当前范围适配、城市标签和选中对象定位。本地底图无瓦片 Token 依赖。
- 债务风险、融资成本、到期压力和银行敞口共用同一企业集。移动地图不会改变分析范围；明确筛选和问数定位才改变范围。
- 企业下探借款、银行、授信、项目、事件、担保及指标输入。支持连续返回、关系网络缩放与复位、成本风险矩阵和明细 CSV。
- 同屏固定业务口径问数：实体/别名解析、筛选、到期分析、银行敞口、担保关系、风险解释、模拟参数提取和事项发起。支持历史成功、失败、取消状态。
- 独立方案：浮息利率、银行范围、授信收缩、到期展期，实时重算、保存、应用、双方案比较。历史风险评分不随模拟改变。
- 事项确认、负责人和截止日调整、开始处理、完成、取消、重开及完整本地处理记录。
- 分析/问数/事项生成报告，标题和结论编辑、固定借款快照、HTML 导出、人工复核冻结和独立修订草稿。
- 保存与恢复探索，保留筛选、视图、地理/关系相机、方案与版本依据；即使原方案被删除，也可从探索中的固定方案恢复。
- 本体规则修订：成本偏离规则归入集团融资本体，偿债缺口规则归入企业债务风险本体。使用原生规则编辑器修改、保存、模拟验证，再用于地图、问数和报告；正式版本不被覆盖。
- 原有数据工程、本体管理、智能问数、审批决策、Agent、报告中心、对象探索、模型目标与驾驶舱完整继承，并继续在同一平台中运行。
- 态势、问数和行动各归其业务模块：经营驾驶舱“融资与风险态势”、M03“地图联动问数”、M04“融资方案推演/分析复核事项”、M06“联合分析报告”。M01取消“融资规则验证”独立任务，规则归属于对应本体的原生修订草稿；M02的9个模拟资产直接登记于原数据资产目录。
- 数据资产支持卡片/列表、名称检索、详情、字段字典、完整记录分页查询、快照身份、来源与血缘、返回驾驶舱和校验后的Excel下载。完整文件为11张工作表、300条记录，下载前校验大小与SHA-256。
- 联合报告可写入原报告内容块编辑器，继续编辑、排序、删除、撤销、预览、导出，并返回原联合分析的固定范围与方案。

## 推荐演示路径

1. 保留原首页进入方式，从“运营与智能 → 融资与风险态势”进入地图。M07中的原对象发现、六种分析Lens和资源内容继续保留。
2. 打开环保测试公司4，下探借款及银行，再返回企业。点击指标查看实际参与计算的借款和输入口径。
3. 问“找出高成本且有资金缺口的企业”，查看同屏地图与企业集同步变化。
4. 问“未来90天如果降息50bp，授信收缩30%，展期180天”，进入方案，调整假设并比较。
5. 从方案发起事项，分办、处理、完成，生成复核报告；复核后修订不覆盖旧版本。
6. 在本体管理的“语义资产”中选择对应本体的“规则与指标修订”，从规则资源进入原生编辑和验证。回到经营态势后核对本体、草稿、规则和数据身份。

## 数据与边界

观察日固定为 **2025-12-31**，“未来90天”等窗口均相对于该观察日。事项办理日期使用当前系统日期。

21家企业沿用统一身份 `ENT-001` 至 `ENT-021`。84笔借款、63条授信、9条担保、21个项目和21个事件属于明确标识的演示构造。三个主体融资总额与成本对齐既有来源，但合成借款不是原始借据。城市坐标不是实际注册地址，全球地图不代表存在海外持仓。

新问数是受约束的确定性语义解析，不是开放式大模型问答。不支持的企业、时间窗口、币种或统计口径会拒绝，不以看似合理的答案替代。

“闭环”指本地交互、计算和状态闭环，不代表银行批准、真实交易、外部通知、生产审批、多人持久化或正式模型发布。v1.3 的资源、内容和工作区是直接继承，不是重新简化实现；联合融资明细是单独登记的增量演示资源，不替换原模块的事实数据或缺失值。

浏览器本地存储清空后不能恢复记录；存储失败时会明确提示仅保留当前会话。业务数据生产接入、地图服务审图与授权、真正的风险重算及外部审批集成需要另行实施。

## 验证与文件

```sh
npm test
npm run verify
npm run verify:workbench
npm run verify:baseline
npm run verify:snapshots
npm run build
npm audit
```

浏览器回归默认调用本机 Google Chrome；其他安装位置可指定 `CHROME_PATH`。回归启动独立临时端口和独立浏览器会话，结束时自动关闭，不改用户预览状态。

- `src/domain.js`：严格数据校验、Decimal 金额计算、语义意图、场景投影、任务状态机。
- `src/store.js`：独立本地状态、撤销、固定报告和任务依据。
- `src/map.js`：地图、聚合、框选和地理相机。
- `composite/`：继承的 v1.3 平台、资源、业务模块、报告编辑器与工作上下文。
- `composite/integrations/joint-workbench.js`：原模块任务扩展、同平台导航、企业身份和报告交接。
- `src/app.js`：联合态势模块与业务交互，嵌入时没有重复的侧栏和顶栏。
- `scripts/build-data.mjs`：可重复生成演示源数据，不写历史目录。
- `scripts/build-snapshot-package.mjs`：生成完整Excel、字段字典、资产快照目录与文件校验信息；使用Codex内置Node与Artifact Tool，依赖位置可通过 `CODEX_NODE_MODULES` 指定。基础数据变化后须重新生成快照包。
- `composite/integrations/snapshot-assets.js`：原数据资产目录的模拟快照详情、查询、下载和血缘交互。
- `public/data/portfolio.json`：本版唯一运行数据资源。
- `artifacts/verification/result.json`：实际浏览器验证结果；同目录保留截图和导出样例。
- `artifacts/inherited-platform/result.json`：新旧模块集成流程验证。
- `composite/evidence/`：本轮重新执行的 v1.3 继承流程、正式报告、模型周期及三档视口验证。
- `INHERITANCE-MANIFEST.json`：45个继承文件的父版本指纹及初始继承指纹。
- `V13-INHERITANCE-REVIEW.md`：本轮纠偏、继承矩阵与入口位置。
- `COCKPIT-SNAPSHOT-REVIEW.md`：态势迁移、完整快照资产化和本轮验证。
- `IMPLEMENTATION-REVIEW.md`：严谨性、下探体验及旧版保留审视。
- `DATA-AND-MAP-SOURCES.md`：来源、身份裁决和演示假设。

本轮性能修正：停止同项目重复预览服务，消除M01重复DOM观察器循环和M02固定轮询，取消平台装饰SVG永久动画。空闲状态不持续重绘。
