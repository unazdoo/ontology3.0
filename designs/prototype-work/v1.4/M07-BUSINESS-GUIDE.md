# M07 对象全景使用说明

业务全景以企业为主入口，把本体中定义的企业、融资、部门预算及相关业务记录连接起来。当前主目录包含23个企业、4个金融产品、3个产品汇总持仓。企业预算仍从企业下钻；集团融资总览和投资产品分析集是视图入口，不作为实体。

## 统一的对象全景入口

一级导航统一为「对象全景」。原经营驾驶舱的经营内容并入这一入口，包含对象发现、单对象画像、业务范围总览、集团融资、企业预算、债务风险、贷前业务、投资业务以及融资与风险地图。

单对象画像回答“这家企业或这个产品怎么样”。集团、投资台账等业务范围全景回答“这一范围内的经营状况怎么样”，再下探到具体对象。集团汇总和投资分析范围仍是视图，不新建虚构的企业或正式投资组合。

贷前业务全景展示已纳入目录的申请主体A/C；投资业务全景展示4个产品、3个汇总持仓及208条实际历史观测。它们以已有业务信息为主，不以资料缺失或等待评价作为主要展示场景。预算总览属于环保测试公司4的演示范围，金额与该公司画像一致，可以直接打开企业画像。

## 对象发现与单对象画像

在对象发现中按对象类型筛选，或按名称搜索。目录不再显示右侧预览，也不在普通浏览时提供多选框。表格保留名称、类型、地区或类别、关键指标、业务状态、风险事件数量、关联业务和实际数据截至日；手机显示相同业务信息的卡片。

点击名称或记录行直接打开完整画像；点击风险事件数量直接进入该对象的事件栏目。画像提供全景画像、关系图谱、事件、适用的时序、证据、行动与进展。属性、地图和历史曲线按对象实际能力展示。

画像地图直接支持滚轮缩放、拖动、手机双指缩放和键盘操作。地图中显示当前及有关联且有已登记位置的对象；点击标记或关联业务卡片，在地图下方查看名称、类型、关键值和关联信息，点击“打开全景画像”才切换对象。

银行等对象没有独立位置时，可以显示与它关联的企业位置，不将企业地址当作银行地址。具有位置的关联对象可以定位、缩放并显示关联范围；地图为城市级演示省界图，不提供街道或真实注册地址。

关系栏目展示直接关系与经业务记录连接的关系。例如企业通过融资借据连接到融资机构，金融产品连接到汇总持仓，银行连接到相关企业。图中用实线/虚线区分，列表保留关系路径、关联记录数量和关键值，并支持类型筛选及分页。

“本体画布”打开当前对象精确的已发布定义并定位类型节点。数据和关系都有本体绑定，浏览关联对象不会重新创建实体。

## 围绕对象进行问答

在画像顶部点击「围绕此对象提问」，在右侧对话面板提问，页面保持当前对象。关闭面板回到画像，切换对象时使用该对象自己的会话，返回原对象可以继续原会话。

可询问基本情况、经营指标、预算执行、风险事件、关联对象、持仓历史与办理进展。例如：

- 公司4：「预算执行情况如何？」「2024年预算执行情况如何？」「有哪些风险事件？」「为什么？」
- 金融产品：「持仓发生了什么变化？」「与哪些对象有关联？」
- 融资机构：「关联哪些企业？」「这个对象的基本情况如何？」

答案列出实际数值、观察日期和可展开的依据；可以从答案打开相关对象。追问沿用上一问题的主题，其他无关企业的问题不会悄悄改变当前范围。当前为基于已发布事实的原型问答，不是开放式大模型预测；不支持的问题会明确提示可询问的业务范围，不编造原因、收益或交易建议。

对象级“加入业务报告”和预算“加入报告”按钮已取消。现有报告中心与已固定报告继续保留。

## 对照查看：先选目的，再挑对象

1. 在目录或画像点击「对照查看」。从单个对象进入时可带入当前对象，从业务范围全景进入时保留其范围。
2. 先选择查看目的：基本信息并排、同类业务指标对照，或具有实际多时点观测的历史走势。没有适用历史时不提供走势选项。
3. 在同一面板搜索、勾选对象，确认下方“将展示的对象”名称。至少选择两个对象，且所选目的有共同口径，按钮才可执行。
4. 点击「并排查看基本信息」「查看指标对照」或「查看持仓走势」，直接得到对应结果。普通目录不会被自动纳入分析范围。
5. 使用「修改对照」调整目的或对象。移除标签也进入同一面板，应用前原结果保持不变；取消可回原结果。
6. 关闭对照后返回发起位置，包括目录、原对象画像或原业务范围全景；保留相关筛选和位置。下探单个画像后可以返回原对照，业务范围全景下探后也可返回原范围。

基本信息可跨类型查看。数值对照要求共同属性或时序定义、单位及版本一致，按每个对象的实际截至日展示。四个以内按列对照，较大范围按行分页，避免无限横向铺开。

基金B与D可以比较其关联汇总持仓的市值、投资金额、损益和现价。图表使用相同时间范围和纵轴，保留实际观测日。持仓规模与价格变化不作为产品收益率或优劣排名。

## 事件从哪里来

事件是需要关注的风险事实或预警，不等同于任何一条对象记录。

| 来源 | 何时形成事件 | 应保留的依据 |
| --- | --- | --- |
| 本体规则 | 指标直接命中已发布业务规则 | 规则名称与版本、命中值、判断条件、求值截至日、来源记录 |
| 模型监控 | 模型结果满足已发布的预警条件 | 模型及版本、运行批次、输出结果、监控条件、评估时点和形成时间 |
| 业务事实 | 业务系统确认发生逾期、违约、评级调整等事项 | 原始事件编号、发生时间、来源系统和业务证据；人工核实录入也应标明来源 |

本轮实际接入前两类：三条既有融资规则命中，以及正式债务风险模型的预警。后者按已发布模型包的黄、红、黑分档与行动条件形成，绿灯评分不生成事件。公司4显示融资成本规则命中和模型红灯预警，各自保留准确来源版本。

事件栏目可按来源筛选，查看触发条件、数值、时间和证据；“查看本体规则”“查看监控模型”定位对应来源，返回后保留原对象和栏目。模型入口使用该模型结果自身的数据及语义版本，避免混用企业目录版本。

业务事实来源已在设计和展示分类中区分，本轮没有虚构外部风险事件或新增人工登记业务。合同临近到期等时间条件可以由规则或模型产生预警；还款实际逾期则可以来自业务系统的事件记录。

普通风险评分留在关键指标中；承接、处理、完成等办理日志留在“行动与进展”。办理完成不等于风险解除，不会自动更改评分或删除原事件。本轮按固定评估批次读取模型结果，没有新增后台实时轮询或把候选/压力试算当作正式风险事件。

## 先体验公司4的预算

1. 进入「对象全景 → 对象发现」，搜索「环保测试公司4」并打开画像；也可从「企业预算全景」点击「查看企业画像」。
2. 企业全景先显示融资和风险事实，继续向下查看「企业预算 · 2025年」。
3. 企业预算汇总为费用预算1,097.70万元、实际费用861.7265万元、执行率约78.50%。下方按设备管理部、技术部、安全运行部列出责任部门。
4. 点击部门对应的「查看明细」，进入该部门年度预算，查看预算、实际费用、实际收入、执行率和成本占收比。
5. 点击「查看科目期间明细」，查看该部门该年度的16条科目与季度记录；记录分页显示，可以打开单条明细。
6. 使用「返回企业全景」回到同一家企业，或查看部门年度预算，比较2024与2025年的历史记录。
7. 点击「询问预算情况」或「围绕此对象提问」，在画像右侧询问企业或部门年度预算，答案可下探相关部门记录。

**企业归属说明：**原预算来源只有部门，没有登记到现有21家企业中的某一家。按用户要求，本轮将它归到环保测试公司4作为演示映射，保留原预算金额、来源和加工口径。该归属不代表原工作簿确认这些部门真实属于该企业。年度和科目季度数据沿用原预算模块；科目季度明细保留其既有演示分配标识，不冒充原工作簿逐行明细。

手机端按部门显示预算卡片，可以直接看到预算、实际费用、执行率、成本占收比和明细入口。

## 企业、属性、记录与集合如何区分

| 内容 | 在系统中的位置 |
| --- | --- |
| 企业 | 主目录对象，具有统一身份；不同业务角色不在主目录重复创建同一企业 |
| 所属板块、分类 | 企业属性，用于理解、检索和分组；沿用各自来源口径 |
| 责任部门 | 企业下的关联对象，承担预算责任 |
| 年度预算与科目期间明细 | 有独立稳定身份的业务记录，从企业和部门下钻 |
| 单笔融资借据 | 按原借据编号识别的融资对象 |
| 75笔融资等集合 | 关联记录的入口，不能当成一笔融资 |
| 集团融资总览 | 汇总视图，保存范围和来源，不作为企业对象 |
| 投资产品分析集 | 可用于查看产品和分析的对象集，不虚构正式组合编号、管理人或账户 |
| 产品汇总持仓 | 按现有台账范围与产品识别，不拆未登记的账户或交易批次 |
| 持仓时点观测 | 同一持仓在不同日期的观测，日期不会生成新的产品或持仓主体 |

融资主体、融资机构和融资负责人等既有类型继续保留；企业通过明确关系与原融资主体身份衔接，主目录展示统一企业，并保留产品和持仓入口。规则、指标、行动分别保留自己的本体资源类型。

## 融资如何下探

在公司4页面点击「查看75笔融资」，可以按页浏览和打开原借据编号对应的记录，查看折合人民币余额、原币种、当前利率、融资机构等业务事实。

三家重点企业共301笔融资：公司4为75笔、风电测试公司07为176笔、公司1为50笔。它们的余额分别与原393.134亿元、770亿元、20.016亿元汇总一致。

「集团融资总览」使用原全量5218笔、574个主体的汇总口径；下方三家是当前可下探的重点企业。集团汇总不等于这三家企业之和。

## 投资产品和持仓如何使用

从「对象全景 → 投资业务全景」查看4个产品。打开有持仓的产品后，沿关系进入该产品汇总持仓。

持仓显示现有台账中的市值、投资金额、浮动盈亏与现价；通过「查看指标变化」查看实际观测日期。持仓B保留79个实际观测时点，三份持仓共保留208条日期观测。

本轮没有将投资台账归属到公司4，也没有补造投资账户。预算的企业演示归属与投资台账的持仓范围分别保留。

## 本体定义与来源在哪里查看

1. 在任一对象全景打开「证据」，或点击「数据与口径」。
2. 点击「查看本体中的对象定义」，进入M01中该对象的精确V2定义，查看身份、属性、关系、映射与版本。
3. M01显示「业务全景对象绑定」，说明当前目录所用的对象类型和来源核对状态。
4. 点击「在数据工程查看来源记录」，进入原数据工程中的来源投影，切换数据成员、翻页或下载完整JSON。
5. 用平台顶部「返回对象全景」返回原对象位置。

本轮V2包含11类对象、76个属性、10类关系、8个指标、3条原融资规则和1类原融资行动。M07的665个业务记录实例均通过显式绑定解析到M01定义；目录、下探记录和历史观测的展示层级不同，不会把665条记录全部放到企业首页。

当前业务全景固定使用已验证的V2定义与来源投影。M01草稿不会自动覆盖它；原融资问数、原审批和已固定报告仍保留各自的来源版本。M01中问数/模型的「正式数据启用」状态与M07的目录读取绑定是不同的消费用途。

## 分析和办理

- 时序入口只提供给具有多次实际业务观测的对象；企业快照进入模型模块时使用该对象的实际截至日，返回位置仍保留原探索上下文。
- 比较先选择具有共同业务指标的同类对象，逐行保留实际截至日；不同规则的通用数值容器不混合比较。
- 关系图区分当前节点、图中心和分析对象集。查看节点不自动改变对象集；企业的重要部门关系优先展示，更多借据从集合入口查看。
- 公司4的融资优化和专项风险处置仍进入原M04事项。承接、执行、完成和反馈由原决策中心维护，M07回读真实状态。
- 办理完成不会自动改变融资成本、预算执行或风险分档；经营改善须依据后续业务数据判断。
- 保存书签和复制链接可以恢复工作位置。旧集团、融资集合和预算目录链接按视图迁移，不冒充新业务实例；旧报告的固定数值不被改写。

M07不展示资料补齐、技术质量评级或未核实候选关系作为主要业务剧情。来源校验留在数据工程和本体管理；不适用的业务字段和分析入口不强行显示，也不补零或默认通过。
