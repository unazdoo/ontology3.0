# M07 企业业务全景使用说明

业务全景以企业为主入口，把本体中定义的企业、融资、部门预算及相关业务记录连接起来。当前主目录包含23个企业、4个金融产品、3个产品汇总持仓。企业预算仍从企业下钻；集团融资总览和投资产品分析集是视图入口，不作为实体。

## 对象发现、预览和打开画像

在对象发现中用“对象类型”筛选企业、金融产品或产品汇总持仓，也可按名称搜索。

点击结果行后，右侧预览面板提供基本信息、关系、事件、时序和证据。它用于快速理解对象和选择下一步；点击“打开全景画像”进入完整详情。手机上点击对象卡片打开同样的预览弹窗。

对象详情采用固定栏目：全景画像、关系图谱、事件、时序、证据、行动与进展。适用的地理位置和历史曲线直接展示在画像中。金融产品的曲线来自其明确关联的汇总持仓，保留持仓身份和实际观测日期；没有相应时序的对象不强行制造曲线。

事件栏目统一展示规则判断、风险评估和办理记录，区分“数据截至日”和“实际办理时间”。行动与进展集中展示原决策中心事项、责任人、期限、状态和反馈。

“本体画布”打开当前对象类型对应的精确已发布版本，并定位该类型节点；返回后保留当前对象和详情栏目。“证据”中仍可进入本体定义与数据来源。

## 多对象列表、平铺和比较

1. 在目录中勾选多个对象，可以跨类型、跨筛选累计选择。
2. 点“比较 / 平铺”进入多对象工作台；顶部“当前对象集”和“管理对象集”都能打开范围弹窗，取消勾选后应用，或回目录添加对象。
3. “基本信息列表”适用于所有对象集，按名称、类型、状态、截至日和地区/类别逐行查看。
4. “维度平铺”将各对象并列为卡片，可选通用信息或共同指标；点卡片进入该对象画像，再返回同一对象集。
5. “时序并列”适用于存在同口径历史的对象。比如选择基金B与基金D，可选择市值、投资金额、损益或现价，两图使用相同的时间范围与纵轴尺度，并保留各自实际观测日。
6. “指标对比”支持共同静态指标或区间最近观测。日期不同则分别列示，避免把不同观测日混成排名。
7. 混合对象或没有共同指标的集合仍可使用列表和平铺；不会仅因为数值单位相同就合并比较。不适用的比较方式禁用。
8. 保存探索会保留对象集、展示方式、维度和日期；复制链接、刷新和报告“返回来源”均恢复这些选择。报告导出使用当前展示内容和完整选中范围。

## 先体验公司4的预算

1. 进入「业务全景」，搜索「环保测试公司4」，或点击目录侧边的「环保测试公司4 · 企业预算」。
2. 企业全景先显示融资和风险事实，继续向下查看「企业预算 · 2025年」。
3. 企业预算汇总为费用预算1,097.70万元、实际费用861.7265万元、执行率约78.50%。下方按设备管理部、技术部、安全运行部列出责任部门。
4. 点击部门对应的「查看明细」，进入该部门年度预算，查看预算、实际费用、实际收入、执行率和成本占收比。
5. 点击「查看科目期间明细」，查看该部门该年度的16条科目与季度记录；记录分页显示，可以打开单条明细。
6. 使用「返回企业全景」回到同一家企业，或查看部门年度预算，比较2024与2025年的历史记录。
7. 点击「将企业预算加入报告」，在原报告中心编辑、预览和导出；点内容块「返回来源」恢复企业全景。也可在问数中分析这家演示企业的三个部门。

**企业归属说明：**原预算来源只有部门，没有登记到现有21家企业中的某一家。按用户要求，本轮将它归到环保测试公司4作为演示映射，保留原预算金额、来源和加工口径。该归属不代表原工作簿确认这些部门真实属于该企业。年度和科目季度数据沿用原预算模块；科目季度明细保留其既有演示分配标识，不冒充原工作簿逐行明细。

手机端按部门显示预算卡片，可以直接看到预算、实际费用、执行率、成本占收比和明细入口。

## 企业、属性、记录与集合如何区分

| 内容 | 在系统中的位置 |
| --- | --- |
| 企业 | 主目录对象，具有统一身份；不同业务角色不在主目录重复创建同一企业 |
| 所属板块、分类 | 企业属性，用于理解、检索和分组；沿用各自来源口径 |
| 责任部门 | 企业下的关联对象，承担预算责任 |
| 年度预算与科目期间明细 | 有独立稳定身份的业务记录，从企业和部门下钻 |
| 单笔融资借据 | 按原借据编号识别的融资对象 |
| 75笔融资等集合 | 关联记录的入口，不能当成一笔融资 |
| 集团融资总览 | 汇总视图，保存范围和来源，不作为企业对象 |
| 投资产品分析集 | 可用于查看产品和分析的对象集，不虚构正式组合编号、管理人或账户 |
| 产品汇总持仓 | 按现有台账范围与产品识别，不拆未登记的账户或交易批次 |
| 持仓时点观测 | 同一持仓在不同日期的观测，日期不会生成新的产品或持仓主体 |

融资主体、融资机构和融资负责人等既有类型继续保留；企业通过明确关系与原融资主体身份衔接，主目录展示统一企业，并保留产品和持仓入口。规则、指标、行动分别保留自己的本体资源类型。

## 融资如何下探

在公司4页面点击「查看75笔融资」，可以按页浏览和打开原借据编号对应的记录，查看折合人民币余额、原币种、当前利率、融资机构等业务事实。

三家重点企业共301笔融资：公司4为75笔、风电测试公司07为176笔、公司1为50笔。它们的余额分别与原393.134亿元、770亿元、20.016亿元汇总一致。

「集团融资总览」使用原全量5218笔、574个主体的汇总口径；下方三家是当前可下探的重点企业。集团汇总不等于这三家企业之和。

## 投资产品和持仓如何使用

从目录侧边进入「投资产品分析集」，查看4个产品。打开有持仓的产品后，沿关系进入该产品汇总持仓。

持仓显示现有台账中的市值、投资金额、浮动盈亏与现价；通过「查看指标变化」查看实际观测日期。持仓B保留79个实际观测时点，三份持仓共保留208条日期观测。

本轮没有将投资台账归属到公司4，也没有补造投资账户。预算的企业演示归属与投资台账的持仓范围分别保留。

## 本体定义与来源在哪里查看

1. 在任一对象全景打开「证据」，或点击「数据与口径」。
2. 点击「查看本体中的对象定义」，进入M01中该对象的精确V2定义，查看身份、属性、关系、映射与版本。
3. M01显示「业务全景对象绑定」，说明当前目录所用的对象类型和来源核对状态。
4. 点击「在数据工程查看来源记录」，进入原数据工程中的来源投影，切换数据成员、翻页或下载完整JSON。
5. 用平台顶部「返回业务全景」返回原对象位置。

本轮V2包含11类对象、76个属性、10类关系、8个指标、3条原融资规则和1类原融资行动。M07的665个业务记录实例均通过显式绑定解析到M01定义；目录、下探记录和历史观测的展示层级不同，不会把665条记录全部放到企业首页。

当前业务全景固定使用已验证的V2定义与来源投影。M01草稿不会自动覆盖它；原融资问数、原审批和已固定报告仍保留各自的来源版本。M01中问数/模型的「正式数据启用」状态与M07的目录读取绑定是不同的消费用途。

## 分析和办理

- 时序入口只提供给具有多次实际业务观测的对象；企业快照进入模型模块时使用该对象的实际截至日，返回位置仍保留原探索上下文。
- 比较先选择具有共同业务指标的同类对象，逐行保留实际截至日；不同规则的通用数值容器不混合比较。
- 关系图区分当前节点、图中心和分析对象集。查看节点不自动改变对象集；企业的重要部门关系优先展示，更多借据从集合入口查看。
- 公司4的融资优化和专项风险处置仍进入原M04事项。承接、执行、完成和反馈由原决策中心维护，M07回读真实状态。
- 办理完成不会自动改变融资成本、预算执行或风险分档；经营改善须依据后续业务数据判断。
- 保存书签和复制链接可以恢复工作位置。旧集团、融资集合和预算目录链接按视图迁移，不冒充新业务实例；旧报告的固定数值不被改写。

M07不展示资料补齐、技术质量评级或未核实候选关系作为主要业务剧情。来源校验留在数据工程和本体管理；不适用的业务字段和分析入口不强行显示，也不补零或默认通过。
