## 已继承的业务功能

- 对象发现：按企业、金融产品、产品汇总持仓分类，先进入明细列表，再打开单对象画像；地图与时序为通用视图入口。
- 地图：按分析视角重排企业，使用不同的企业/银行图标；聚焦时淡化其他对象。右键或“关系显示”选择融资、授信、担保，支持全局关系、取消选择和来源核对。
- 时序：企业、板块与集团融资成本曲线，按本金加权；新增24个月独立演示历史，可切换208个已有持仓观测。支持附加3种可维护预测模型、叠加固定运行、方案送审及保存恢复。
- 对象全景：与原经营驾驶舱合并，位于本体管理下面；预算演示归属环保测试公司4，持仓采用台账范围内的产品汇总粒度。
- 模型与算法：围绕三个目标绑定输入资产、维护算法、声明输出、模拟核验和发布版本。企业业务结果在对象分析／时序视图消费，维护区保留调试样例及下游引用。
- 融资成本目标：存量融资成本预测按原台账重定价；AI 推荐融资置换按同评级银行相近期限优先、板块均值兜底，支持悬停解读与逐笔询价事项；存量合同延续仅作历史趋势外推。
- 数据工程、本体管理、智能问数、审批决策、Agent 和报告中心继续沿用原模块及跨模块交接。

决策中心统一为事项工作台与运营总览；方案推演位于对象分析上下文，执行后的效果复核属于同一事项阶段。

详细操作见 [对象全景使用说明](M07-BUSINESS-GUIDE.md)、[模型与算法使用说明](MODEL-ALGORITHMS-GUIDE.md)、[决策中心使用说明](DECISION-CENTER-GUIDE.md) 和 [数据与地图来源](DATA-AND-MAP-SOURCES.md)。

新增时序操作和数据边界见[时序分析说明](TEMPORAL-ANALYSIS-GUIDE.md)。导航统一为一条可折叠的两级菜单；同工作区切换复用页面，跨页面切换保留原画面至目标就绪。

## 版本与数据隔离

v1.5 使用新端口及本地存储命名空间（`ofw.prototype.v1.5.*`、`ofw.v1.5.workbench.*`、`ofw.m07.v1.5.*`、`ofw.v15.*`）。从全新浏览器状态开始，不自动迁移 v1.4 的个人方案、模型发布或办理记录。

产品版本升级不改变业务数据版本。数据 `DATA-V14-20251231-DEMO-1`、本体 `ONT-ENTERPRISE-FINANCE-RISK-1.4`、已发布本体定义、对象身份和源指纹保留。受保护资源中的 v1.4 字样是原始来源或协议身份，不能批量改名。`INHERITANCE-MANIFEST.json` 记录 v1.4 父文件指纹及本次初始化指纹；`LEGACY-INHERITANCE-MANIFEST.json` 保留更早的继承记录。

本轮按用户要求增加独立的模拟历史资产 `DATA-FINANCE-HISTORY-DEMO-2025-V1`，包含21家企业的504条月末记录。它通过源指纹关联既有快照；历史月份为虚构演示，期末与原快照校准，不覆盖既有数据。

原台账补充资产 `public/data/finance-contract-assets.json` 包含3家既有映射企业的301笔借据及5218笔银行可比融资记录。重定价首次日、周期、计息天数来自原工作簿；原工作簿没有信用评级字段，缺失保留且使用明确的板块兜底，不能以历史风险评分代替。新模型与旧模拟历史的输入口径分别保存。

本工作区的 v1.4 和 `designs/prototype-releases/` 为参考基线。后续功能修改写入 v1.5；生成脚本使用 v1.5 输出目录。旧版截图和验收记录未复制为本轮证据。
