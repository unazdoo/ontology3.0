## 已继承的业务功能

- 对象发现：按企业、金融产品、产品汇总持仓分类，显示对象数量；企业下探包含地图、关系网络、成本 × 历史风险和对象明细。
- 企业探索：按分析视角重排企业和红黄绿状态；选中企业显示关联银行、球面连接线及短时动效；单对象画像保留相关对象、内嵌地图、问答与事件依据。
- 对象全景：与原经营驾驶舱合并，位于本体管理下面；预算演示归属环保测试公司4，持仓采用台账范围内的产品汇总粒度。
- 模型与算法：融资成本预测、债务结构优化、债务风险监测三个目标，覆盖创建目标、维护数据范围和算法、核验、发布版本、使用及结果追溯。
- 数据工程、本体管理、智能问数、审批决策、Agent 和报告中心继续沿用原模块及跨模块交接。

详细操作见 [对象全景使用说明](M07-BUSINESS-GUIDE.md)、[模型与算法使用说明](MODEL-ALGORITHMS-GUIDE.md) 和 [数据与地图来源](DATA-AND-MAP-SOURCES.md)。

