# 决策中心：统一事项工作台

决策中心统一接收不同业务领域的待处理事项、分析方案、问数/模型结果、Agent和报告申请。导航只有“事项工作台”和“运营总览”；工作台是办理入口，运营总览查看整体进度。

两项入口已并入统一可折叠左栏。工作台保留按当前范围生成事项摘要的能力。每个事项直接展示「研判参考」与「本事项从哪里来」，原风险事项复用原型的建议、评分组成、低分指标与调节因子；「打开完整追溯」直接进入原申请的全链路，返回时仍定位原事项。

“融资方案推演”不再是决策中心菜单。原融资条件推演、保存方案和两方案比较仍可在企业探索的“比较方案 / 已保存方案”使用。方案送入工作台后保存为固定附件。原“分析复核事项”并入同一工作台，不再维护第二张事项清单。

## 工作台怎样使用

工作台按待研判、待批准、待执行与执行中、待复核、已结束和需补充或恢复筛选同一批事项。来源与负责人是筛选条件，不构成新的菜单。当前没有登录岗位权限系统，因此显示全部负责人，不把“我”冒充实际授权角色。

原申请继续使用原审批引擎：工作台打开对应申请或待办后，仍须完成其证据校验、人工确认、分办、承接与办理。原C017质量检查、驳回、补充、失败重试与重复提交约束保留。

从对象分析、模型结果或工作台新建的事项首先待研判。各阶段使用同一事项编号，保存原对象、时间、窗口、数据与本体版本、方案/模型运行及指纹。

| 阶段 | 主操作 | 结果与恢复 |
|---|---|---|
| 待研判 / 退回补充 | 写明拟采取措施，提交待批准 | 转待批准；可取消或调整负责人 |
| 待批准 | 批准并指定负责人、期限 | 转待承接；可退回补充或拒绝并记录原因 |
| 待承接 | 执行人确认承接 | 转执行中，尚未执行完成 |
| 执行中 | 登记执行日、凭证和进展 | 有凭证后方可确认执行完成 |
| 效果待复核 | 依据后续观察日和材料登记复核 | 达成后结项；未达成或依据不足继续待复核 |
| 已结项 / 待复核 | 补充处理或重开 | 原历史保留，补充事项关联原事项及复核结论 |

凭证与效果依据为人工填写的材料编号或来源引用；本地原型记录这些声明，不自动验证外部材料。不按完成状态自动改写资金、成本、预算或风险事实。

## 来源与异常

提交和批准前核对固定快照与事项对象、版本、原模型运行；不一致时阻止推进并提供来源入口。其他页面修改过事项时，旧页面不能覆盖新状态。取消未提交表单不改变事项；退回、拒绝、重开和调整均保留处理人、原因与历史。

“回到来源”恢复固定范围、时间和方案或模型结果。“打开对象画像”查看同一对象及关联办理进度。“生成固定复核报告”将当前办理记录及效果结论固定到报告中心草稿；重复点击同一版本不重复添加，后续变化形成另一次固定引用。

时序预测可连同利率、展期等方案形成待研判事项。固定模型运行、版本、方案、输入快照与形成时间均进入来源链；后续模型修改不覆盖已提交事项中的曲线和依据。

没有凭证不能执行完成；没有晚于原依据日的后续材料不能宣称效果达成。效果结论为“未达成”或“依据不足”时，仍显示在待复核中，可以登记进一步复核或发起关联的补充事项。
