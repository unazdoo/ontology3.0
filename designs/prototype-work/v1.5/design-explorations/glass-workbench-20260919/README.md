## 动效设计

- 切页：主面板淡入、14–22px位移，430–620ms，面板错开55ms。参数为本次设计取值。
- 对象切换：地图650ms平滑移动；关系线720ms一次描绘；详情面板340ms淡入。
- 抽屉：310ms淡入和32px横向移动。
- 动效演示：约3.2秒，先进入、再定位/重点反馈、最后静止，不改变业务状态。
- 没有后台轮询、永久动画或装饰性循环。切页、Esc、页面隐藏时取消旧动画；系统减少动态效果偏好和手动低动效开关均有效。
- 玻璃层使用backdrop-filter与半透明背景，文字保持实色；深色表格、边框和局部底色保障阅读。浏览器不支持模糊时仍有基础色层。
