# 智财问策 · 大屏视觉方案评审

本项目是2026-09-18的独立视觉选型，不修改当前原型的业务页面、路由、状态、数据或本体版本。选择方案后才开展全量前端改造。

## 设计条件

- 同一产品、同一业务内容，比较三种完整界面语言，覆盖问数工作台、地图视图、决策中心、本体工作台，共12个页面状态。
- 默认会议屏1920×1080，同时检查1440×900和2560×1440。采用真实布局响应，不把桌面截图放大。1920档主结果以15–18px为主，主结论28–44px；背景装饰不常驻运动。
- 使用当前v1.5代码和数据作功能基线，仓库没有可绑定的顶层设计系统。各方案用独立CSS变量管理颜色、排版、间距和组件。
- 设计内容与操作使用独立预览状态；图表数据来自现有演示快照，办理状态和新增事项是选型演示，不读写正式原型存储。

## 三个方向

| 方案 | 视觉与布局 | 适合场景 |
|---|---|---|
| A 明晰蓝白 | 深蓝侧栏、明亮工作区、清楚的三栏分工；蓝色强调主要行动 | 日常操作和正式演示共用，建议优先考虑 |
| B 深海指挥台 | 深色全屏、顶部模块导航、横向指标与大面积地图；青绿数据强调 | 暗场会议、展厅和专题演示 |
| C 暖白研判室 | 米白纸感、墨绿与铜色、编辑式标题与线性分隔；证据和结论并置 | 管理层评审、业务讲解和长时间阅读 |

| 跨模块 | 对象、时间、范围、数据版本、本体版本、证据、模型运行、历史记录 | 统一上下文条、来源入口、带对象的跨页面跳转 | 不重建业务身份，不以视觉选型样例替换正式数据 |
