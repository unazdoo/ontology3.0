# M08 一期范围与后置能力

> 状态：研究范围建议。当前不代表 M08 已正式立项

## 1. 一期目标

一期只建立“目标定义—候选比较—人工评审—研究发布候选—稳定 Binding—不可变模拟—三态比较”的最小公共合同，并用 S005 合成数据证明隔离和确定性。

一期不以训练平台、在线服务平台或自动决策平台为目标。

## 2. 一期必须包含

### 模型治理

- 1 个 Modeling Objective Revision；
- 2-3 个 Candidate Model 和不可变 Model Version；
- Experiment 与 Evaluation Run 分离；
- 同一 training/evaluation data version、精确 transaction、feature/evaluator/metric schema 下比较；
- 输入、输出、特征、评估集、指标、环境、作者、评审和版本全链追溯；
- 人工批准是 Release Candidate 的硬门；
- Release Candidate 与 Published/Production/T019 明确分开；
- 1 份无 endpoint 的 Ontology Binding 草案。

### 数字孪生与模拟

- 1 个不可变 Simulation Baseline；
- 少量 Parameter Set/Case；
- 1 个单模型 Run 和 1 个两节点复合 Run；
- DAG 依赖、循环、类型、单位、时间粒度和 domain compatibility 校验；
- 节点失败/跳过和不可晋级的 partial result；
- FACT/PREDICTION/SIMULATION 独立身份、权限、视觉和导出语义；
- 禁止历史 Action、通知、审批、待办和交易重放；
- 结果只读 Comparison，绝不覆盖事实。

### S005 验证

- 只使用合成/缩放夹具；
- 明确当前 target/label 未裁决；
- 指标只评工程适配，不宣称预测准确；
- 利率/利差/评级/流动性/赎回参数标 ASSUMED；
- 覆盖成功、失败、越界、数据不足和不兼容状态；
- 形成自动化证据和可复算脚本。

## 3. 一期明确不做

- 自动调参、AutoML、任意训练代码托管；
- GPU 集群、成本/配额平台；
- 实时在线推理、低延迟 SLA、复杂流量路由；
- 复杂求解器、Monte Carlo 市场、组合自动优化；
- 大规模 3D/地图数字孪生；
- 跨组织模型共享/市场；
- 自动选择 Production Model；
- 把实验候选登记为 Published Model/Metric/Rule 或写 T019；
- Scenario Apply、事实写回、Action Request、审批、待办、通知、Webhook 或交易；
- 用 LLM 计算分数、执行模拟、选择候选或作正式结论；
- 把模型配置写入数据工程管道；
- 复制 Palantir 页面、品牌、RID 或内部实现。

## 4. 后置能力与触发条件

| 后置能力 | 进入条件 |
|---|---|
| 真实 S005 历史回放 | 业务 target/label、分类/基准、最低历史、公式/权重/硬门已裁决，且数据补齐 |
| 批式预测物化 | M01/M02/M08 Binding/Result Owner 和事实隔离 CR 生效 |
| Live inference/Model Function | 有明确业务延迟要求、权限/审计/SLA/成本合同和安全评审 |
| 自动评估调度 | 评估集维护 Owner、版本、权限和失败重试合同生效 |
| GPU/大模型平台 | 有已批准的非确定性/高算力模型场景和成本预算 |
| 复杂复合模拟 | 简单 DAG 生产验证通过，单位/时间/domain registry 稳定 |
| Scenario 持久化/协作 | 三态权限、保留期、分享和审计合同生效；仍不得 Apply |
| 优化建议进入决策 | M04 新建独立人工桥，重读最新 FACT，明确拒绝模拟直接执行 |
| 自动交易 | 不在默认路线；需独立立项、合规、风控和用户明确批准 |

## 5. 一期技术验证门

已达到：

- 零依赖 Node 验证包可运行；
- 29/29 自动测试通过；
- 3 候选固定 fingerprint 比较；
- 人工硬门、research release candidate、无 endpoint Binding 通过；
- 单模型/复合模拟成功；
- 循环/单位/时间/类型/参数/数据不足/失败传播被验证；
- 三态写入隔离和零副作用被验证；
- 机器证据 `overallStatus=PASSED`。

未达到：正式产品基线、平台合同生效、真实数据回放、用户评审、生产权限/存储/调度/性能和正式验收。

## 6. 正式立项前置门

必须同时满足：

1. 四场景组合正式冻结，形成精确 commit、不可变目录/清单、正式 Checkpoint 和回退指针；
2. M08 完成重基线，`rebaseRequired=false`；
3. 平台批准新资源、Owner、三态、Binding、数据交付、发布/回退和 Action 拒绝合同；
4. S003 C035 特例的保留/迁移策略明确；
5. S005 业务目标和评价方法由用户确认；
6. 脱敏等级、密钥管理和仓库可存范围通过安全裁决；
7. 真实回放证明可解释、可复算和有区分度；
8. M01-M08 依赖模块完成各自正式评审；
9. 平台总控明确授权 M08 正式立项。

当前结论：只满足继续公共研究与隔离验证，不满足正式立项门。
