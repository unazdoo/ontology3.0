# M07-M08 全链路体验重构

> 原型版本：`m08-s001-v1.1.0-baseline-additive.4`
> 活动实现基线：v1.1.0
> 状态：隔离研究原型；`acceptanceReady=false`

## 1. 重构目标

旧界面同时暴露 A/B/C 布局方案、五个 Lens、模块回链和 M08 卡片，用户无法判断当前任务、下一步和结果归属。本轮改为一条任务链：

```text
选择对象
  -> 观察与定位
  -> 确认模拟上下文
  -> M08 运行
  -> 返回 M07 并列查看
```

M07 和 M08 均作为 v1.1.0 父壳中的独立研究模块挂载，不渲染第二套平台壳。

## 2. M07 信息架构

### 始终可见

- 当前场景、ObjectRef、数据截至、本体版本、质量和用途权限；
- 四步工作链及每步状态；
- 当前对象和下一项推荐操作。

### 第一栏：选择对象

- 按单位、风险或稳定 ID 搜索；
- 当前对象高亮；
- 切换对象会重置 Lens 访问状态，不复制或改写对象事实。

### 第二栏：观察和定位

- 对象概览：属性、质量、权限、版本、证据；
- 关系网络：仅获准 Published 一跳关系；
- 时间变化：观测事实、3 个月滚动均值、窗口和观察摘要；
- 空间位置：无权威 GeoRef 时直接显示“不适用”，不绘制假地图。

### 第三栏：带着发现继续

- 汇总当前对象、窗口、数据版本和观察；
- “形成模拟上下文”先展示确认对话框；
- 只有确认后才进入 M08。

## 3. 交接合同

M07 发送 `ofw.m07.m08-handoff.v1`：

```text
ObjectRef
+ focusBaselineMemberRef
+ LensRef / SeriesRef
+ timeRange / observation
+ dataVersionId / ontologyVersionId / bindingId / asOf
+ recommendedCaseId
```

父壳只在 session 级研究命名空间保存交接，不写当前组合 localStorage，不携带成功状态或生产运行编号。

M08 把上述字段固化为 `ofw.m08.case-input.v1`。对象映射到合成 Baseline member：

| M07 ObjectRef | Simulation Baseline member |
|---|---|
| `FIN-UNIT-553` | `SYN-HOLDING-001` |
| `FIN-UNIT-465` | `SYN-HOLDING-002` |
| `FIN-UNIT-561` | `SYN-HOLDING-003` |

对象、观察窗口、情景或版本任一变化后，当前结果进入 stale 状态；旧结果继续显示其原始输入，但禁止以当前输入返回 M07。

## 4. 返回合同

M08 成功运行后发送 `ofw.m08.m07-return.v1`：

- 固定 input manifest；
- Simulation Run/Result ID；
- 当前对象价值影响；
- 组合价值影响；
- 模拟评价分数；
- 状态和副作用计数。

M07 收到后进入时间 Lens。若 ObjectRef、窗口或版本不一致，明确显示“结果对应另一组探索上下文”，用户可显式恢复对应上下文；不会静默改绑。

## 5. 浏览器验证

已验证：

- v1.1.0 父壳新增“探索分析”入口，M01-M06 canonical 页面字节不变；
- 搜索、对象切换、概览、关系、时序和空间不适用状态；
- M07 确认上下文后进入 M08；
- 旧结果在输入变化后显示 stale，返回按钮禁用；
- 重新运行后单位553对象影响约 `-4.31 百万元`，单位465约 `-5.12 百万元`；
- 组合价值影响约 `-11.74 百万元`，模拟评价分数 `43.3245`；
- 返回 M07 后可检测上下文匹配或显式恢复；
- 1440x900 与 390x844 无页面级横向溢出，控制台无应用错误；
- 空间 Lens 不加载地图或生成坐标。

验证通过不代表 M07/M08 正式立项、真实数据 API 完成、用户评审通过或一期验收。
