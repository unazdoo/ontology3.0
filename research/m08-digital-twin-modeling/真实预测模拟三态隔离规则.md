# 真实、预测、模拟三态隔离规则

> 状态：研究合同草案。视觉差异是辅助，资源身份、权限和存储隔离才是强门

## 1. 三类身份

| 状态 | 资源身份 | 必须追溯 | 允许写入 | 建议权限 |
|---|---|---|---|---|
| FACT | 由业务事实 Owner 发布的 Object/Property/Evaluation Result | Published Ontology、T019、T007/T008、as-of、事实 Run | 只能由原 Owner 的正式流程写入 | `fact.read` 及原 Owner 写权限 |
| PREDICTION | `resultKind=PREDICTION` 的 Model Result | Objective、Model Version、Binding Revision、input data version、as-of、coverage | 只能写预测结果域；不得写事实 Property | `prediction.read`，单独的结果写权限 |
| SIMULATION | `resultKind=SIMULATION` 的 Simulation Result | Baseline、Case、Parameter Set、Graph、全部 Model Version、Run | 只能写 M08 隔离结果域 | `simulation.read`，运行时无事实/行动写权限 |

同一对象可以被三态引用，但三个 Result ID、存储键、权限、as-of 和证据链必须不同。不能通过改颜色把同一数据库字段解释成三种状态。

## 2. 存储与命名空间

研究运行固定 `ofw.m08.research.v1`，不读取或写入当前组合的 localStorage。建议持久层分区：

```text
facts/<owner>/<published-version>/...
predictions/<objective>/<model-version>/<result-id>
simulations/<baseline>/<case>/<simulation-run>/<result-id>
```

事实域由 M01/M02/场景 Owner 管理；M08 只持有引用。预测/模拟不能使用事实主键进行 upsert，也不能共享“当前结果”指针。跨域 Comparison 只存引用。

## 3. 权限硬门

1. 模拟运行身份只具备读取 Baseline 所需的最小权限和写入自身 Run/Result 的权限。
2. 模拟身份不在 M04、通知、Webhook、Schedule、交易连接器或 extended-function allowlist 中。
3. M04 必须拒绝 `sourceResultKind=PREDICTION|SIMULATION`，除非未来另有用户明确批准的正式合同；本期一律拒绝。
4. M07/M06 只获得安全投影，不获得模型 endpoint、原始参数密钥或事实写权限。
5. 权限不足显示 `RESTRICTED`，不能伪装成“无结果”或“零”。
6. 预测/模拟写事实域必须以 `NON_FACT_WRITE_REJECTED` 阻断，并留审计记录。

## 4. 状态转换禁令

明确不存在以下转换：

```text
PREDICTION -> FACT
SIMULATION -> FACT
SIMULATION -> PREDICTION
SIMULATION RESULT -> ACTION REQUEST / APPROVAL / TODO / TRANSACTION
HISTORICAL ACTION -> SIMULATION REPLAY
```

若未来业务接受某个预测，需要由事实 Owner 通过独立人工/业务流程形成新事实，引用原预测但不改写其 `resultKind`。如果用户基于模拟做决策，需要重新进入真实上下文、重读最新事实和权限，再手工发起独立 Action Request；本期不建设此桥。

## 5. 视觉语义

建议在 M07/M06 消费层同时显示文本标签、图例和形态，不只依赖颜色：

| 状态 | 文本标签 | 图形语义 | 时间语义 |
|---|---|---|---|
| FACT | 已观测/真实 | 实线、实心标记 | 事实 as-of 和来源版本 |
| PREDICTION | 预测 | 虚线、空心标记 | prediction as-of + horizon |
| SIMULATION | 模拟/假设 | 斜纹或点划线、Case 标签 | baseline as-of + scenario horizon |

颜色需保持无障碍对比，但不得成为唯一编码。列表、导出、API 和报告必须携带文字 `resultKind`。

## 6. M07 与 M06 边界

M07 拥有 Lens Definition、Session、布局、筛选和深链；它读取三态安全包络，不能缓存冲突副本、重算结果或改变 `resultKind`。模拟真值归 M08，真实事实仍归 M01/M02。

M06 拥有报告/仪表盘定义和正式展示产物；它可以并列 FACT/PREDICTION/SIMULATION、形成固定证据和历史比较，但不能重算模型/模拟或把模拟结论写入正式事实章节而不标注。

两者都必须保留原 Result ID、版本、as-of、coverage、权限和证据深链。

## 7. 历史与恢复

- 历史 FACT 只读；不为模拟复制其成功状态或历史 Action。
- 历史 PREDICTION/SIMULATION 只读，不因新模型/参数覆盖。
- Clone/Regression 创建新的 Run ID 和命名空间；来源 Result 只作引用。
- 失败恢复不能复用旧 `scenarioRunId`；重试保留 `retryOf`。
- Baseline 或模型版本变化必须形成新 Case/Run/Comparison，旧结果仍可复算。

## 8. 隔离验证证据

验证包形成三个不同 ID 和权限：

| resultKind | 研究结果 ID | 合成分数 | 权限 | 视觉语义 |
|---|---|---:|---|---|
| FACT | `FACT-EVAL-S005-SYNTHETIC-0001` | 72.4 | `fact.read` | `OBSERVED_SOLID` |
| PREDICTION | `PRED-0e46df8b9ec2fed1` | 64.9209 | `prediction.read` | `PREDICTED_DASHED` |
| SIMULATION | `SIMRES-205612029a927ebb3a4f` | 43.3245 | `simulation.read` | `SIMULATED_HATCHED` |

以上数值全部是合成接口证据，不代表任何真实产品评价。Comparison 固定 `overwriteAllowed=false`；预测/模拟事实写入测试均被拒绝；两次成功模拟 `sideEffectAttempts=0`、`sideEffectsEmitted=0`。

## 9. 导出与文案

所有 CSV/JSON/报告导出必须把 `resultKind`、Result ID、baseline/input version、model/graph version、as-of、coverage 和 evidence 放在数据行或元数据中。标题不得只写“评价结果”；应写“真实评价”“模型预测”或“模拟结果”。模拟假设必须使用“如果/假设/情景下”，不得用“将会”冒充事实。
