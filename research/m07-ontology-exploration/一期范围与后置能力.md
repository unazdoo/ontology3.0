# M07 一期范围与后置能力

> 状态：研究范围建议，不表示 M07 已正式立项
> 当前结论：`baselineStatus=待正式冻结`、`rebaseRequired=true`、`acceptanceReady=false`

## 1. 启动事实与硬冲突

1. 当前组合为未冻结 `v1.1.0-rc.10` 候选，`acceptanceReady=false`；不能作为 M07 正式来源基线。
2. 当前 Foundation、C034 和模块资源注册只承认 M01—M06；M07 没有正式 module ID、Owner、导航或 Checkpoint 位置。
3. 平台可复用 C004/C007、C008/T019、C017、C033/C034，但消费者名单和查询能力尚未覆盖 M07。
4. 当前没有对象实例分页、对象 360、时序/空间引用、角色视图或百万级生产性能合同；本研究已有本地合成算法证据，但不包含平台端到端链路。
5. 当前权限只能模拟；没有可关闭正式安全门的真实角色负向证据。
6. S005 只有研究型周快照与候选身份，尚无 Published Ontology、T019 或权威空间数据。

因此，一期在现阶段只能是**隔离研究和技术验证范围**。完整产品建设、总装汇入、正式立项与验收均未获授权。

## 2. 一期最小范围（建议）

### 2.1 用户能力

| 能力 | 最小行为 | 完成证据 |
|---|---|---|
| 对象目录与统一搜索 | 按 Published Object Type、获准属性和 typed filter 搜索；游标分页；诚实空/拒绝/质量状态 | 同一 ObjectRef 可从目录进入其他四 Lens；无名称猜测或本地对象副本 |
| 对象 360 | 属性、关系、质量、精确版本和证据 section | 每 section 独立状态；权限/质量/证据缺失按规则关闭 |
| 关系图 | 一至两跳、Link 白名单、方向/筛选、增量分页、稳定布局 | 不把布局写成关系；截断、未加载和无关系可区分 |
| 时序探索 | 最多 8 系列叠加；滚动聚合、差分、受控阈值引用、事件定位 | 系列身份/粒度/单位/时间语义完整；缺失不填 0、不伪造日频 |
| 空间探索 | 图层、bbox/范围筛选、对象定位和获准关系展开 | GeoRef/CRS/有效时间/几何版本可证；无几何显示不适用 |
| Lens 切换与深链 | 五 Lens 共用 ObjectContext；保留对象、时间、地图、筛选、选择与返回位置 | 打开时重新鉴权并重读版本/质量；无成功状态或权限 token 入 URL |
| 状态覆盖 | 不适用、缺数据、质量警告/阻断、权限拒绝、版本错配、证据缺失、上游不可用 | 正负用例及可恢复行为齐全，不以静态页面冒充 |

### 2.2 平台合同范围

- `LensDefinition`、`ExplorationSession`、`ExplorationQueryRun`、`LayoutState`、`DeepLinkContext`、`RoleViewBinding` 的最小身份和生命周期；
- `ObjectRef`、`TimeSeriesRef`、`GeoRef` 等只读引用，不另建真值；
- 对象/关系/时序/空间通用请求结果包络、游标、限额和错误码；
- C004/C007/C008/C017/C033 的固定与传播规则；
- M07 与 M01/M02/M03/M04/M06 的 Owner 边界；
- C034 参与方式的 CR 设计，不在研究分支直接修改 Foundation。

### 2.3 一期界面边界

- 第一屏是实际对象目录/搜索工作区，不做宣传落地页；
- 五 Lens 使用同一对象上下文、状态条和证据入口；
- 所有可见按钮必须有真实行为、明确阻断或不适用解释；
- 数据来自研究验证资源或未来 Owner 查询响应，不把 DOM 常量当查询结果；
- 端口固定 `4356`，存储和事件命名空间固定 `ofw.m07.research.v1`，不得碰组合/场景现有键。
- M07 不直接改变业务状态；需要行动时只能带稳定上下文调用平台标准 Action 入口，并由相应 Owner（当前为 M04）重新执行其权限、C017 和人工确认门。未登记 M07 为合法 C011 来源前，研究 Lens 不显示可提交按钮。
- 交互和文案可借鉴业务上清晰的探索模式，但不复制 Palantir 的名称、品牌、页面结构或专有产品组合；本研究只记录可迁移的机制和边界。

## 3. S005 首个验证范围

### 3.1 可以验证

| 数据事实 | 验证项 |
|---|---|
| 79 份周快照，2025-02-21 至 2026-07-17 | 周粒度、非规则日期、范围缩放、系列切换和深链恢复 |
| 32 个跨期产品候选身份，9 个覆盖全部 79 期 | 同一研究引用跨搜索/360/关系/时序保持一致 |
| 产品持仓和固收暴露时点值 | 属性/系列、差分的技术呈现和证据定位 |
| 2025-10-20 固收整表缺失 | `source_missing`、不插值、不沿用前值、质量传播 |
| 产品/管理人/发行人/持仓目标模型 | ObjectRef/LinkRef 的适用与合同缺失状态 |

### 3.2 不能据此验证

- S005 Published 发现、真实 T019/C008 或 C017 正向交换；
- 管理人对象身份（来源无字段）；
- 发行人正式身份及 Link（仅名称级候选）；
- 日频净值、完整 TWR/MWR、现金流、交易事件、基准或全市场同类；
- 权威空间几何；
- 正式权限隔离；
- 百万对象、长时序或百万空间要素性能。

原型应使用脱敏、不可逆研究 ID，并在界面标注“研究验证资源 / 非 Published”。不能把 S005 投资字段写入平台通用合同；通用合同只保留对象、属性、关系、观测、几何和证据概念。

## 4. 性能与响应式关闭门（建议）

### 4.1 性能

| 门 | 最低验证 |
|---|---|
| 百万对象 | 1,000,000 对象索引、选择性权限和游标分页；搜索 p95 <= 1.0s |
| 对象 360 | 100 属性/20 Link 类型；关键摘要 p95 <= 1.5s |
| 关系 | 一跳 p95 <= 1.5s；默认不超过 500 节点/1,000 边；两跳显式加载 |
| 长时序 | 8 系列、10 年日频等价；服务端降采样后首屏 p95 <= 2.0s |
| 大量空间 | 百万要素源的矢量瓦片/聚合；视窗首屏 p95 <= 2.0s |
| 稳定性 | 错误率、超时率、内存峰值、缓存冷/热 p50/p95/p99 均记录 |

一期不得用 S005 小数据运行时间关闭这些门。当前 `performance/results.json` 已用固定种子合成数据完成 100 万对象、100 万节点/1200 万边、100 万时序点、50 万空间点的 10/10 本地内存算法门；它不含数据库、网络、权限、并发、序列化和浏览器绘制，不能关闭生产端到端门。若无生产等价服务，可关闭“候选算法可行”研究项，但正式立项门保持未满足。

### 4.2 响应式

- 至少验证 1440×900、1280×720、390×844；无页面级横向溢出；
- 关系图/地图/时序拥有稳定 `aspect-ratio`、最小高度和受控面板折叠；
- 长标题、状态、证据标识、筛选和值不互相覆盖；
- 移动端保留核心选择、状态和返回，不假装支持桌面同密度的多栏并排；
- 键盘焦点、屏幕阅读标签、色彩以外状态编码和 reduced motion 均验证。

## 5. 与现有模块不重叠的定义

| 模块 | 该模块拥有 | M07 一期只做 | 越界判定 |
|---|---|---|---|
| M01 本体管理 | 定义、映射、Published、T019、模型验证预览 | 发现并查询已发布资源/对象 | 出现定义编辑、Draft 发布、T019 切换、对象真值维护即越界 |
| M02 数据工程 | 来源、管道、T007/T008、质量、权威业务值 | 按引用查询并展示 C017 | 直读工作簿/T002、修数据、定义质量规则即越界 |
| M03 智能问数 | 自然语言理解、C009/C010、可固定 C018、BI/CSV | 提供对象驱动探索和可返回深链 | 生成正式自然语言答案、复制 C018 或 ChatBI 即重叠 |
| M04 决策中心 | C011、提醒、人工确认、待办和状态机 | 一期仅导航到标准 Owner 入口 | 提交（未 CR）、确认、执行、分派或复制状态即越界 |
| M06 报告中心/仪表盘 | 正式驾驶舱、报告定义/布局/编排/发布 | 临时探索 Lens 和对象上下文 | 经营驾驶舱、正式卡片、报告产物或发布生命周期即重叠 |

## 6. 明确后置

| 后置能力 | 原因/前置 |
|---|---|
| 通用无代码应用构建器、自由字段拖拽与脚本 | 超出 Lens 配置，容易复制 BI/应用平台和绕过语义治理 |
| 任意公式、Metric/Rule/阈值编辑 | 定义 Owner 为 M01 |
| Action 提交/确认/待办 | C011 当前来源不含 M07；需单独 CR，确认和待办仍归 M04 |
| 正式仪表盘/报告发布 | 归 M06；M07 仅深链或稳定引用 |
| 复杂 GIS 编辑、地理编码、空间分析模型、3D 地球、离线地图 | 需权威空间数据、算法和治理合同 |
| 实时流式大屏、秒级告警 | 需流式数据、SLO、质量和 M04 事件合同 |
| 任意 Python/SQL 导出执行、大规模异步导出 | 安全、成本、血缘和 M03/M02 边界未定 |
| 协同批注、跨用户共享 Session、公开链接、跨租户共享 | 真实身份、内容治理和撤权未实现 |
| 自动系列发现、预测、异常检测、空间推断 | 可能形成新 Metric/Rule/模型；需 M01/M08 等 Owner 裁决 |
| 复杂图算法、三跳以上、全图导出 | 性能、权限推断和业务用途不足 |

## 7. 一期验收矩阵（建议）

| 关闭门 | 隔离研究可关闭 | 正式模块必须额外关闭 |
|---|---|---|
| 五 Lens 功能 | 真实研究资源驱动、按钮可用、正负状态通过 | 真实 M01/M02 API 和 Published/T019/C017 交换 |
| 身份一致 | 研究 ObjectRef 一致性 | Owner 签发正式 ObjectRef，不按名称/夹具生成 |
| 权限 | 模拟角色传播逻辑 | 真实身份、用途、对象/属性/Link/证据负向及撤权缓存测试 |
| 质量/版本/证据 | 受控夹具 fail-closed | C008/C017/C033 正负交换和 Owner 证据定位 |
| 深链 | 4356 隔离路由、上下文恢复 | 平台公共导航、短 token、安全审查和跨模块回链 |
| 性能 | 脚本/夹具/测量方法 | 生产等价百万对象、长时序、大空间证据 |
| C034 | 研究导出格式 | CR 后 MODULE_IDS、Checkpoint、恢复/回归/迁移联调 |
| S005 | 79 周脱敏验证 | 正式 S005 Published、身份、T019、质量与空间来源（适用时） |

## 8. 是否满足正式立项门

当前**不满足**。至少存在以下硬阻断：组合未正式冻结和重基线未完成；M07 未登记为模块；Owner/合同未裁决；真实权限不可验证；对象/时序/空间查询合同未由 M01/M02 接受；S005 无 Published；虽有百万级合成本地算法证据，但没有生产等价端到端性能证据。

内部检查、隔离原型或 S005 小样本通过，只能支持用户评审是否值得立项，不能改写 `acceptanceReady=false`，也不能表述为 M07 一期验收通过。
