## 2. 资源建模原则（建议）

1. **引用而不复制**：M07 保存稳定引用、呈现配置和运行证据，不保存 Object Type、Property、Link、对象业务值、Metric、Rule、Action Type、T019 或 C017 的第二份真值。
2. **定义与运行分离**：`LensDefinition` 描述可复用的查看方式；`ExplorationSession` 描述一次用户运行；结果缓存不是资源真值。
3. **精确版本优先**：所有正式读取固定精确 C007 Published 版本、C008 投影和数据版本；名称、“当前版”或页面状态不能替代身份。
4. **场景身份正交**：C033 关联探索发生在哪个场景轮次，但不替代对象、Lens、查询或证据稳定标识。
5. **权限不随视图放大**：角色视图只收窄属性、关系、默认筛选和动作入口；不得授予底层没有的访问权。
6. **未知即关闭**：权限、版本、质量、证据、对象身份或适用性任一无法判断时，返回明确状态并阻断相应数据，不以空数组、0、上一次结果或静态夹具伪装成功。

## 3. 资源目录（建议）

### 3.1 M07 自有资源

| 资源 | 稳定身份与版本 | M07 Owner 内容 | 明确不拥有 |
|---|---|---|---|
| `LensDefinition` | `lensId + revision` | Lens 类型、允许对象类型、属性/关系引用、默认筛选、列/图层/系列呈现、角色适用条件、深链策略、状态 | 语义定义、业务值、公式、阈值、权限授权、正式报告布局 |
| `ExplorationSession` | 不可复用 `sessionId`；带创建/到期时间 | 一次运行固定的 Lens 修订、C033、版本上下文、用户筛选、选择对象、时间/空间窗口、返回位置和查询 Run 引用 | 对象或数据副本、长期业务记录、权限凭据、Action 状态 |
| `ExplorationQueryRun` | `queryRunId`；不可变完成记录 | 请求规范化摘要、固定上下文、状态、耗时、分页/聚合计划、结果摘要哈希、证据定位和失败原因 | 返回业务事实的权威副本、质量真值、正式计算口径 |
| `LayoutState` | `layoutId + revision` 或 session 内瞬态值 | 关系图坐标、展开/折叠、列宽、图层顺序、图例和面板布局 | 关系存在性、空间几何、业务排序口径 |
| `DeepLinkContext` | `contextId + revision` 或带版本的受控 token | 可恢复的对象、Lens、筛选、时间、地图范围、选择和返回位置 | 登录态、授权结果、查询成功状态、业务结果数据 |
| `RoleViewBinding` | `bindingId + revision` | 角色/用途到 Lens 的适用关系和进一步收窄规则 | 角色定义、成员关系、数据授权；不得物化一份角色专属数据 |

`LensDefinition` 的“启用”只表示 M07 配置可被选择，不是 C007 Published，也不表示底层对象可消费。建议状态流转为 `draft -> active -> needs_review -> retired`（`needs_review` 也可回到新 revision 的 `active`）；每次影响查询或深链语义的修改形成新 revision，旧 revision 只读保留。`needs_review` 只表示所绑定 Published 资源发生变化、需人工核对，不允许系统自动改绑。

### 3.2 只读引用值对象

下列对象是请求/结果中的不可变引用，不在 M07 建立独立生命周期。

| 引用 | 最小身份 | 权威来源 | 缺失行为 |
|---|---|---|---|
| `PublishedResourceRef` | `publishedVersionId + resourceType + resourceId` | M01 C004/C007 | 无精确 Published 版本或资源不在允许发现范围时拒绝 |
| `AuthoritativeBindingRef` | `c008ProjectionId + projectionVersion + semanticVersionId + dataVersionId` | M01 C008/T019 | `empty`、损坏、错轮次、不可消费或无法读取时阻断正式查询 |
| `ObjectRef` | 稳定 `objectTypeId + opaqueObjectId`，另固定解释它的 `publishedVersionId` | 待新增的获权对象查询合同；对象类型语义归 M01，值归 M02 权威数据 | 禁止按标题、产品名称、证券代码或研究伪名猜测；Published 版本不是对象身份 |
| `PropertyRef` | `publishedVersionId + objectTypeId + propertyId` | M01 C004/C007 | Draft、同名或版本不一致时拒绝 |
| `LinkRef` | `publishedVersionId + linkTypeId + direction` | M01 C004/C007 的允许发现 Link 范围 | Link 未获准、端点错配或方向未知时拒绝 |
| `TimeSeriesRef` | 上游稳定 `seriesId`，回指 `ObjectRef + PropertyRef + seriesVariant/dimensionSet`，并锁定权威数据版本 | 语义身份归 M01，系列/观测值/时间/质量归 M02 | 上游没有正式系列身份/时间语义时显示“不适用/合同缺失”，不由 M07 拼装 |
| `GeoRef` | `ObjectRef + PropertyRef + geometryMemberId`，并锁定几何版本 | 语义归 M01，几何/CRS/有效时间/质量归 M02 | 几何、CRS 或有效时间缺失时不渲染，不把地址文本猜成坐标 |
| `TrustRef` | C017 两类摘要各自的 `id + version + formedAt`、T007/T008 与证据定位 | M02 C017 | 未知、错版本、证据不可定位或硬质量失败时按传播规则阻断 |
| `ScenarioContextRef` | C033 五字段 | 平台公共层 | 缺失、停用、未知或错轮次时拒绝进入当前投影 |

### 3.3 资源关系

```text
LensDefinition@revision
  -> PublishedResourceRef[]             (只读语义引用)
  -> RoleViewBinding[]                   (只收窄)
  -> Layout defaults                     (呈现)

ExplorationSession
  -> LensDefinition@revision
  -> ScenarioContextRef                  (C033)
  -> AuthoritativeBindingRef             (C008/T019)
  -> TrustRef                            (C017)
  -> ObjectRef / TimeSeriesRef / GeoRef  (只读引用)
  -> ExplorationQueryRun[]
  -> DeepLinkContext / LayoutState
```

任何箭头均不表示 M07 复制目标资源。删除或退休 Lens 不得删除 M01/M02 资源、历史查询证据、C033 轮次或 C034 Checkpoint。

`opaqueObjectId` 是对象稳定身份分量，`publishedVersionId` 是本次如何解释类型、属性和 Link 的精确上下文。跨 Published 版本只有 M01 明确给出兼容/替代关系时，才可确认两个 ObjectRef 指向同一现实对象；M07 不因 `opaqueObjectId` 字符串相同而自行跨版合并。

## 4. 最小字段（建议）

### 4.1 LensDefinition

{
  "schemaVersion": "ofw.m07.lens-definition.v1",
  "lensId": "LENS-OBJECT-360-DEFAULT",
  "revision": 1,
  "status": "draft",
  "lensType": "object360",
  "name": "对象概览",
  "purpose": "authorized-object-inspection",
  "owner": { "moduleId": "M07", "ownerId": "OWNER-TO-BE-DECIDED" },
  "supportedObjectTypes": [
    { "publishedVersionId": "SEMANTIC-VERSION-ID", "resourceType": "objectType", "resourceId": "OBJECT-TYPE-ID" }
  ],
  "propertyRefs": [],
  "linkRefs": [],
  "defaultFilters": [],
  "presentation": {},
  "roleViewBindingRefs": [],

研究夹具中的 `SEMANTIC-VERSION-ID` 等占位值必须标记 `researchOnly=true`，不能伪装成 Published 响应。

  "schemaVersion": "ofw.m07.exploration-session.v1",
  "sessionId": "M07S-OPAQUE-ID",
  "namespace": "ofw.m07.research.v1",
  "subjectContextRef": "AUTH-CONTEXT-OPAQUE",
  "purpose": "ontology-exploration",
  "scenarioContext": {
    "scenarioId": "S005",
    "scenarioVersion": "S005-v1",
    "scenarioRunId": "S005-RUN-...",
    "formedAt": "2026-08-24T00:00:00.000Z",
    "status": "active"
  },
  "lensRef": { "lensId": "LENS-OBJECT-360-DEFAULT", "revision": 1 },
  "bindingRef": {},
  "trustRef": {},
  "selection": { "objectRefs": [], "timeRange": null, "mapViewport": null, "filters": [] },
  "queryRunRefs": [],
  "createdAt": "2026-08-24T00:00:00.000Z",

`subjectContextRef` 仅为权威身份/授权服务返回的不可解释引用。不得保存角色声明、组列表、访问 token 或授权后的业务行集合。

## 5. Owner 与写入边界（建议）

| 范围 | 唯一 Owner | M07 行为 | 失败关闭规则 |
|---|---|---|---|
| Object Type、Property、Link、Metric、Rule、Action Type、Published 生命周期 | M01 | 经 C004/C007 精确发现，只读引用 | 找不到精确版本、状态非 Published 或资源不在发现范围即拒绝 |
| T019/C008 权威组合 | M01 | 每次新会话和正式查询固定并复核 | 不可定位、`empty`、错轮次、版本变化或不可消费即阻断/废弃当前 Run |
| 对象/时序/空间业务值、T007/T008、质量事实 | M02 | 只经获准查询与 C017 读取 | 不直读源表、工作簿、T002/T007 明细；未知或硬失败按范围阻断 |
| 场景身份与 Checkpoint 编排 | 平台公共层 | 原样传播 C033；未来经 CR 参与 C034 | M07 未纳入 MODULE_IDS 前不得声称 Checkpoint 包含 M07 |
| Lens、会话、查询 Run、布局、深链上下文 | M07（待正式登记） | 创建、修订、到期、只读历史 | 不得包含其他 Owner 的完整定义或业务行副本 |
| 自然语言问数、C009/C010/C018 | M03 | 可从 M07 深链过去或接受稳定对象引用（需合同） | M07 不生成自然语言正式回答，不复制 C018 查询定义 |
| Action Request、提醒、确认、待办 | M04 | 一期不提交；只允许导航到既有标准入口 | C011 当前合法来源不含 M07，未 CR 前隐藏/禁用提交能力并说明原因 |
| 仪表盘、正式报告及发布生命周期 | M06 | 提供带上下文的只读探索回链（需合同） | 不保存正式卡片、报告定义、布局或发布状态 |

## 7. 资源模型关闭门

本草案只有同时满足以下条件，才可提交正式模块设计评审：

1. 当前四场景组合正式冻结，M07 完成重基线并记录精确冻结版本和快照；
2. 用户裁决 M07 是正式模块、M01 子能力或继续仅研究；
3. 总控 CR 登记 M07 Owner、模块 ID、导航、C033/C034 参与方式及 C004/C007/C008/C017 消费资格；
4. M01/M02/平台安全 Owner 共同确认 ObjectRef、TimeSeriesRef、GeoRef 和查询执行边界；
5. 真实身份与权限负向测试可用，不再仅依赖模拟角色；
6. 至少一个场景形成真实 Published 对象、权威数据版本和可定位 C017 证据；
7. Lens/Session 不复制真值、版本漂移、权限撤销、质量硬失败、错轮次和证据缺失的负向验证通过。

在这些门关闭前，`acceptanceReady=false`，也不满足 M07 正式立项门。
