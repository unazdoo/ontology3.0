# 对象、时序与空间最小查询合同

> 状态：研究合同草案；合同代号仅为 `M07-Q-*` 研究占位符，不占用平台 C 编号
> 适用范围：对象搜索、对象 360、关系展开、时序和空间 Lens 的只读查询
> 核对日期：2026-08-24

## 1. 已确认前置与合同缺口

### 1.1 已确认事实

- M01 通过 C004/C007 拥有 Published Object Type、Property、Link Type 及版本发现；M01 通过 C008/T019 唯一原子提交权威语义/数据组合。
- M02 拥有 T007/T008、业务数据版本、质量事实和 C017 可信度摘要。
- C033 场景五字段必须原样传播；错轮次不能进入当前投影。
- M07 只读消费，不维护对象真值、Metric/Rule/Action Type 定义或业务状态。

### 1.2 当前不存在的能力

当前平台没有对象实例搜索/游标分页、对象 360、关系一至两跳、时序系列、空间几何或统一探索结果合同。因此本文件定义的是**建议输入与关闭门**；隔离适配器返回成功不能证明 M01/M02 已提供这些接口。

## 2. 通用请求包络（建议）

所有请求必须先固定同一个读取上下文，再执行具体查询：

```json
{
  "schemaVersion": "ofw.m07.query.v1",
  "queryId": "M07Q-OPAQUE-ID",
  "queryKind": "object.search",
  "requestedAt": "2026-08-24T00:00:00.000Z",
  "purpose": "ontology-exploration",
  "subjectContextRef": "AUTH-CONTEXT-OPAQUE",
  "scenarioContext": {
    "scenarioId": "S005",
    "scenarioVersion": "S005-v1",
    "scenarioRunId": "S005-RUN-...",
    "formedAt": "2026-08-24T00:00:00.000Z",
    "status": "active"
  },
  "readContext": {
    "publishedVersionId": "SEMANTIC-VERSION-ID",
    "c008ProjectionId": "C008-PROJECTION-ID",
    "c008ProjectionVersion": "1",
    "c008FormedAt": "2026-08-24T00:00:00.000Z",
    "dataVersionId": "T007-ID",
    "dataAsOfRef": "T008-ID",
    "c017BindingSummaryRef": { "id": "SUMMARY-ID", "version": "1", "formedAt": "2026-08-24T00:00:00.000Z" },
    "c017CurrentSummaryRef": { "id": "SUMMARY-ID", "version": "1", "formedAt": "2026-08-24T00:00:00.000Z" }
  },
  "page": { "limit": 50, "cursor": null },
  "request": {}
}
```

硬要求：

1. `subjectContextRef` 由真实身份/授权服务签发且只作不透明引用；缺失时拒绝，不接受前端传入角色名称代替。
2. `readContext` 的 C008、C017、T007/T008 和 C033 必须属于同一可证明上下文。
3. `queryId` 只用于幂等读取与追踪，不是对象、会话或业务事实身份。
4. 未知字段默认拒绝；未来扩展必须升 `schemaVersion` 或明确声明向后兼容。
5. 筛选只能引用 Published 稳定资源标识和受控操作符，不接受源字段名、任意表达式、脚本或 SQL。

## 4. 对象查询

### 4.1 `M07-Q-OBJ-01 object.search`

请求最小字段：

| 字段 | 要求 |
|---|---|
| `objectTypeRefs[]` | 至少一项；每项固定 `publishedVersionId + objectTypeId` |
| `text` | 可空；非空时限制长度并由服务端使用获准搜索属性 |
| `filters[]` | `propertyId + operator + typedValue`；属性必须在当前 Published 与权限投影中 |
| `sort[]` | 只允许服务端声明的稳定排序；最终必须追加稳定对象 ID 作为 tie-breaker |
| `projection.propertyRefs[]` | 只请求必要的显示字段；默认仅标题和业务可读类型 |
| `page` | 游标分页；一期建议 `limit <= 100`，禁止 offset 扫描百万对象 |

服务端游标必须是不透明、带签名或服务端可校验的 token，并绑定 `queryKind + normalizedRequest + readContext + subject/purpose + Lens revision` 及过期时间。客户端不得修改游标后继续请求其他筛选、版本或身份；绑定不一致返回 `CURSOR_CONTEXT_MISMATCH`，不从第一页静默重启。

每个命中项返回：

- 精确 `ObjectRef`：稳定对象身份分量与本次 Published 解释上下文分列；
- 获权标题、对象类型和允许显示的属性摘要；
- 匹配原因的业务可读摘要，不暴露隐藏字段值；
- 对象级 `quality/access/evidence` 状态；
- `redactedPropertyCount`，但不得借计数泄露敏感集合大小时应省略。

无结果必须区分：`empty`（获权范围内确实无匹配）、`denied`、`redacted`、`quality_blocked`、`context_incomplete`，不得全部显示“0 个对象”。

### 4.2 `M07-Q-OBJ-02 object.get360`

请求以单一 `ObjectRef` 为核心，可选择 `properties / links / quality / version / evidence` 五个 section。返回每个属性和关系的独立状态：

```text
available | null_value | not_observed | not_applicable |
redacted | quality_blocked | version_unavailable | evidence_unavailable
```

禁止：

- 用页面目录中的显示名称重新查对象；
- 将无权限属性转为 `null`；
- 将无关系权限显示为“0 条关系”；
- 在对象 360 中编辑业务值或维护对象真值；
- 把 M01 的模型验证预览缓存当作日常消费 API。

### 4.3 `M07-Q-REL-01 relation.expand`

| 参数 | 一期建议 |
|---|---|
| 起点 | 1—20 个已获权 `ObjectRef` |
| 跳数 | 仅 `1` 或 `2`；第二跳必须显式触发 |
| Link | 只允许 C004/C007 当前版本的 `LinkRef` 白名单 |
| 方向 | `outbound / inbound / both`，必须与 Link 定义一致 |
| 限额 | 每节点/每 Link 类型单独限制，并返回截断原因和继续游标 |
| 结果 | 节点 ObjectRef、边 LinkRef、方向、授权/质量状态和稳定分页 |

布局坐标由 M07 `LayoutState` 产生，不进入关系事实。未返回某边不能推出业务关系不存在；只有服务端明确 `completeForAuthorizedScope=true` 时，才可在获权范围内显示“无关系”。

## 5. 时序查询

### 5.1 系列身份

`TimeSeriesRef` 至少锁定：

```text
upstreamSeriesId
+ ObjectRef
+ PropertyRef
+ seriesVariant 或已排序 dimensionSet
+ timeSemantics (observation/effective/event)
+ nativeGrain
+ calendar/timezone
+ unit
+ authoritative dataVersionId
```

`upstreamSeriesId` 必须由获准的 M01/M02 查询合同签发并在同一身份语义内稳定；M07 不得用“对象 ID + 页面指标名称”自行合成正式系列 ID。若 M01/M02 未形成系列身份、单位、时间语义、业务日历/时区或粒度合同，返回 `series_contract_missing`。

### 5.2 `M07-Q-TS-01 timeseries.query`

| 字段 | 规则 |
|---|---|
| `seriesRefs[]` | 一期建议最多 8 条；每条必须单独授权 |
| `range` | ISO 起止；明确时区或业务日历引用；`start < end` |
| `requestedGrain` | 不得细于 native grain；细于周快照的日频请求返回不适用 |
| `aggregation` | 仅白名单 `none/sum/avg/min/max/last/count`；需符合 Property/Metric 合同；M07 不因此创建新的业务 Metric |
| `rolling` | `windowCount + aggregation + minPeriods`；结果标记 derived presentation，不写回业务事实 |
| `difference` | `none/absolute/relative`；必须说明前值缺失和分母为零策略 |
| `thresholdRefs[]` | 只能引用 Published Rule/Property/Metric 的获准阈值引用；M07 不保存新业务阈值，呈现派生须标记为探索结果 |
| `eventRefs[]` | 只读事件 ObjectRef/LinkRef；不能由曲线变化猜测事件 |
| `downsample` | 由服务端返回方法、输入点数、输出点数和是否保留极值；不得浏览器静默抽样 |

每个观测点返回 `observedAt/effectiveFrom/effectiveTo` 中适用字段、值、单位、状态、质量范围和证据定位。滚动、差分、降采样和阈值事件只产生本次 QueryRun 的可追溯呈现派生，不写回 M02，也不能冒充 Published Metric/Rule 结果。缺失策略必须是以下显式值之一：

| 状态 | 含义 | 呈现 |
|---|---|---|
| `not_observed` | 本期没有可证明观测 | 断线/空点，绝不填 0 |
| `not_applicable` | 该对象或期间不适用 | 标注不适用，不参与聚合 |
| `source_missing` | 来源或整表缺失 | 质量阻断/警告，保留证据 |
| `redacted` | 当前主体无权查看 | 不返回原值，不用邻点推断 |
| `quality_blocked` | 硬质量失败影响该点/范围 | 不用于新派生、阈值或 Action |
| `valid_null` | 上游合同允许的业务空值 | 与未观测严格区分 |

S005 2025-10-20 固收整表缺失必须为 `source_missing`；不得前值填充、线性插值或解释为仓位归零。79 份离散周快照不得扩展为日频净值。

## 6. 空间查询

### 6.1 几何身份

`GeoRef` 至少包含：`ObjectRef + PropertyRef + geometryMemberId + geometryType + crs + validTime + geometryVersion/dataVersionId`。地址、区域名称或发行人名称不是几何；地理编码若未来存在，必须是 M02 获权管道形成的新权威数据和证据，不在 M07 即时猜测。

### 6.2 `M07-Q-GEO-01 geo.query`

| 字段 | 规则 |
|---|---|
| `layerRefs[]` | 图层呈现归 Lens；图层数据引用必须指向获准 Published 属性/关系 |
| `viewport` | `bbox + crs`；经度纬度范围、反子午线和极区须由实现明确处理 |
| `timeRange` | 对有效时间/观测时间适用；无时间语义时不得伪造 |
| `spatialFilter` | 一期仅 `intersects/within`；缓冲和距离计算后置或使用获准 CRS |
| `objectFilters[]` | 与对象查询使用同一 typed filter 语义 |
| `relationExpansion` | 空间查询只返回当前 GeoRef 对象的可见关联 ID/回链；一至两跳 Link 的语义图由 `relationshipGraph` Lens 展示，不在地图内复制通用关系图 |
| `resolution` | 大量要素使用服务端聚合/矢量瓦片；返回聚合级别和近似性 |

每个要素必须回指 `GeoRef/ObjectRef`；聚合簇不能充当对象身份。几何无效、CRS 未知、版本错配、有效时间不相交或权限不足时不渲染原几何并返回明确状态。

## 7. 错误码与 fail-closed

| 错误码 | HTTP 建议 | 行为 |
|---|---:|---|
| `AUTH_CONTEXT_MISSING` / `ACCESS_DENIED` | 401/403 | 不返回业务值；保留最小审计标识 |
| `SCENARIO_CONTEXT_INVALID` / `SCENARIO_MISMATCH` | 409 | 拒绝进入当前轮次 |
| `PUBLISHED_VERSION_MISSING` / `RESOURCE_NOT_PUBLISHED` | 409 | 不回退 Draft、同名或“最新版” |
| `C008_UNAVAILABLE` / `AUTHORITATIVE_BINDING_MISMATCH` | 409/503 | 阻断正式查询，不用静态默认组合 |
| `C017_UNKNOWN` / `QUALITY_HARD_BLOCK` | 409/503 | 按影响范围阻断；未知不能当通过 |
| `EVIDENCE_UNAVAILABLE` | 424 | 对需证据的 section/结果阻断，不能生成假定位 |
| `OBJECT_REF_INVALID` / `SERIES_CONTRACT_MISSING` / `GEO_CONTRACT_MISSING` | 422 | 要求修正合同，不按名称拼装 |
| `QUERY_LIMIT_EXCEEDED` | 413/422 | 返回可缩小范围的建议，不截断后冒充完整 |
| `CURSOR_CONTEXT_MISMATCH` | 409 | 游标与请求/版本/权限/Lens 不一致时拒绝，不静默换页 |
| `CONTEXT_CHANGED` | 409 | 当前 Run 标记废弃；用户显式重跑 |
| `UPSTREAM_UNAVAILABLE` | 503 | 保留失败事实；旧缓存只可显著标记历史且不可用于新行动 |

## 8. 性能与规模门（研究建议）

这些是建议的生产端到端目标，不与隔离算法硬门混称：

| 场景 | 负载夹具 | 建议门 |
|---|---|---|
| 对象目录 | 至少 1,000,000 对象，多类型、多权限分区 | 首屏搜索 p95 <= 1.0s；游标页 p95 <= 0.8s；禁止全量传浏览器 |
| 对象 360 | 100 属性、20 Link 类型、受限证据 | 关键摘要 p95 <= 1.5s；其余 section 可并行渐进加载 |
| 关系图 | 1—2 跳，高度节点 | 首跳 p95 <= 1.5s；默认渲染 <= 500 节点/1,000 边，截断有游标和原因 |
| 时序 | 10 年日频等价数据、8 系列 | 服务端聚合后首屏 p95 <= 2.0s；单次返回建议 <= 5,000 点/系列 |
| 空间 | 百万级要素源、视窗查询 | 矢量瓦片/聚合首屏 p95 <= 2.0s；禁止单次返回全量几何 |
| 交互 | 已加载结果缩放、筛选、选择 | 本地交互 p95 <= 100ms；主线程长任务 <= 50ms |

测量必须记录硬件、浏览器、服务端配置、缓存冷/热、数据量、权限选择性、错误率和 p50/p95/p99。S005 79 周小样本只能验证语义与状态，不能关闭百万级性能门。

当前隔离证据：`performance/results.json` 在 Apple M4、Node v22.22.0、单进程单线程、进程内热数据上，以固定种子验证了 100 万对象、100 万图节点/1200 万有向边、100 万时序点和 50 万 WGS84 合成点；结构正确性和 10 个本地硬门全部通过。该结果没有覆盖 JSON 序列化、网络、授权、磁盘/数据库、服务排队、并发、故障恢复或浏览器绘制，因此只能证明候选算法与数据结构可行，不能证明上表生产目标已达成。

## 9. 最小一致性测试

1. 同一 ObjectRef 在五个 Lens 中逐字一致；显示标题变化不改变对象身份。
2. C008、C017、C033 或授权上下文中途变化时，分页、两跳、时序和空间请求均废弃而非混版。
3. 权限移除后旧深链重新读取并拒绝；历史缓存不泄露原值。
4. `not_observed`、`not_applicable`、`redacted`、`quality_blocked` 不得被序列化为同一个 `null`。
5. 关系分页或地图聚合不得把“未加载”显示为“无关系/无对象”。
6. S005 缺失周、无管理人身份、名称级发行人和无权威几何均按合同失败关闭。
7. 超限查询返回缩小范围建议，不截断后标记 `complete=true`。

只有真实 M01/M02/权限服务正负交换和生产等价规模证据才能关闭合同；研究夹具通过只说明消费者实现符合草案。
