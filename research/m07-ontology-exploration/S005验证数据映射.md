## 时序映射

| `TimeSeriesRef` 组成 | 验证值 |
|---|---|
| series identity | `series:holding-XX:{marketValue,investmentAmount,unrealizedPnl,price}` |
| owner | `holding-XX`，由产品关系定位，不复制持仓行 |
| source grain | `P1W-irregular`，按实际快照业务日期，不假设日频 |
| timezone/calendar | `Asia/Shanghai` / `snapshot-business-date` |
| unit | 金额字段 `CNY`；现价保留 `source-price-unit`，不擅自换算 |
| missing semantics | `not_observed`、`missing`、`redacted`、`quality_blocked`、`not_applicable` 分列；缺失保持断线 |
| quality | 每个点带 `quality`；对象、系列和数据绑定质量也分别保留 |
| version/evidence | 每个点带 `snapshotRef=snapshot:YYYY-MM-DD`；来源哈希在 `source.snapshots` |
| 一期变换 | 原值、四点滚动、相邻差分、研究阈值线、变化/中断事件；不是正式 Metric/Rule |

资源检查结果：15 个对象、13 条关系、16 条系列，每系列 79 点；其中首个选择的脱敏对象存在 29 个非观测点，验证了断线与质量状态传播。

## 空间映射

- S005 周快照目前没有可证明的权威 geometry、CRS、地址或地域暴露字段，因此业务产品/持仓在空间 Lens 显示“不适用/未提供”，不生成伪位置。
- 技术夹具使用 WGS84/EPSG:4326 GeoJSON Point，带 `validFrom`、图层和质量状态，用于验证 Leaflet 图层、范围筛选、对象定位、关系展开和 `bbox` 深链。
- 技术夹具明确标记 `technicalFixture=true`，不能进入正式 S005 业务对象、报告、仪表盘或 Action 证据。

## 权限与失败状态验证

| 场景 | 预期 |
|---|---|
| 研究分析员/证据审计员 | 可读取研究资源内允许对象；仍显示质量 blocked 的候选关系 |
| 受限观察员 | 只返回权限列表内对象；深链指向不可见对象显示 `REDACTED/访问拒绝`，不回退到同名对象 |
| 属性被拒绝 | `sourceCode` 显示已拒绝，不等同缺失 |
| 无 geometry | 显示“不适用”，地图仍可显示明确标注的技术夹具 |
| 质量阻断关系 | 可见关系边的阻断状态和原因，不进入已确认业务结论 |
| 基线/Published 占位引用 | 显示 `candidate-not-frozen`，不解释为已建立正式 T019 |

## 不足与后续数据门

进入 S005 完整建设前仍需补充：权威产品/管理人/发行人主数据、正式持仓键规则、净值/收益/风险事件的业务定义、比较基准、按日或明确的周粒度合同、空间暴露来源、质量 Owner、Published 语义版本和 C008/T019 真实回执。研究资源不得越过这些门自行补全。
