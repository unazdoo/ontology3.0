# M07 性能与规模技术验证计划

## 目的与边界

验证 M07 查询适配器在确定性合成数据上的算法预算，不宣称生产后端、网络、并发、权限、数据库、序列化或浏览器 UI SLA。正式验收仍需真实服务端压测与平台 Owner 签署。

## 硬门

| 工作负载 | 夹具规模 | p50 门 | p95 门 | 额外门 |
|---|---:|---:|---:|---|
| 对象目录过滤/排序 | 1,000,000 对象 | ≤20 ms | ≤50 ms | 结果稳定、分页边界正确 |
| 一至两跳关系展开 | 1,000,000 节点 / 12,000,000 边 | ≤20 ms | ≤50 ms | 节点/边预算、无越权节点 |
| 长时序融合/滚动/差分 | 1,000,000 点 | ≤150 ms | ≤250 ms | 缺失不转 0、输出点数可解释 |
| 空间范围查询 | 500,000 WGS84 点 | ≤20 ms | ≤50 ms | bbox 正确、范围外不泄漏 |
| 进程资源 | 同上全套 | - | - | 峰值 RSS ≤768 MiB；构建 ≤30 s |

## 运行方式

```bash
node --expose-gc research/m07-ontology-exploration/performance/benchmark.mjs
```

机器可读结果：`research/m07-ontology-exploration/performance/results.json`。

## 产品级超门策略

1. 对象目录超过页预算时只返回稳定游标和计数，不把截断结果当完整结果。
2. 关系图超过节点/边预算时先收窄跳数或筛选，显示阻断原因；不静默丢边。
3. 长时序超过像素可见点数时先按明确粒度聚合/降采样；保留聚合窗口、缺失策略和版本引用。
4. 空间要素超过视口预算时使用分层加载或 tile；若 tile 模式不支持当前筛选/选择能力，必须显式降级或阻断。
5. 任何性能超门与权限、质量、版本冲突分别记录，不用“加载中”掩盖失败。

当前结果标记 `productionClaim=false`，不构成容量承诺、立项门、模块验收或一期验收。需要真实服务端、真实授权、网络抖动、冷缓存、并发、浏览器内存、跨 Lens 深链和大屏响应式的独立测试。
