# 待用户裁决与 CR 建议

> 状态：研究登记；下列建议未获用户或总控接受
> 规则：不预占正式 D/CR/C/T 编号，不直接修改平台总控、Foundation、组合或 M01—M06 主文档

## 1. 当前结论

M07 可继续做资料研究、合同草案、S005 脱敏夹具和 4356 隔离验证，但**不能按正式模块开工或汇入组合**。硬原因如下：

1. 产品来源仍是未冻结 `v1.1.0-rc.10`，`candidateSnapshotStatus=not-frozen`、`acceptanceReady=false`；M07 仍需在正式冻结后重基线。
2. Foundation `MODULE_IDS`、C034 清单和当前资源注册只包含 M01—M06。
3. C004/C007/C008/C017/C033/C034 尚未正式登记 M07 的消费和导出/恢复责任。
4. 平台没有 Lens/Session/ObjectRef/TimeSeriesRef/GeoRef 或对象/时序/空间查询合同。
5. 权限当前只能模拟，S005 尚无 Published；百万级本地合成算法门已有 10/10 证据，但生产等价性能尚无证据。

## 3. CR 包建议

下列名称均为研究代号。用户先裁决 U-M07-001 后，再由总控分配正式编号。

### CR-M07-A：模块登记与治理

**目标**：若选择独立 M07，登记模块身份、Owner、导航、版本、命名空间和验收边界。

**建议修改范围**：

- 总控 D001/模块表：增加或明确不增加 M07；
- Foundation `MODULE_IDS`、Checkpoint schema/校验、模块导出与恢复引用；
- C033 消费者与定向重置、C034 模块导出/恢复/隔离回归责任；
- 组合资源注册、统一入口和导航；
- 版本注册、回归矩阵、冻结门和 `acceptanceReady` 规则。

**必须保持**：平台公共层不保存 M07 业务结果真值；M07 不接管 M01/M02/M03/M04/M06 资源；历史 Checkpoint 不原地改写。

**当前状态**：待 U-M07-001；硬阻断正式模块建设。

### CR-M07-B：Published 发现与权威读取消费者扩展

**目标**：在不改变 Owner 的前提下，把 M07 加入 C004/C007/C008/C017 的最小获准消费者。

**最小字段/规则**：

- C004/C007：稳定资源 ID、精确 Published、状态/有效时间、可读说明、Link 范围和证据入口；
- C008：投影 ID/版本/形成时间/readStatus、完整 C033、精确 Published/T007/T008、上一可信和恢复说明；
- C017：适合探索用途的两摘要身份、T007/T008、质量/新鲜度、影响范围、证据定位和恢复建议；
- M07 只保存稳定引用，不保存定义/质量/T019 副本；未知、失败或错配全部 fail-closed。

**需 Owner**：M01、M02、平台权限 Owner、M07（若成立）。

### CR-M07-C：对象实例查询与 ObjectRef

**目标**：新增跨 Lens 共用的对象实例发现合同，补足 C004/C007 只覆盖定义发现的缺口。

**最小范围**：

- ObjectRef 分列稳定 `objectTypeId + opaqueObjectId` 和精确 Published 解释上下文；跨版同一性只能由 M01 兼容/替代关系确认；
- 获权对象搜索、typed filter、稳定排序、游标分页和字段投影；
- 对象 360 的属性/关系/质量/版本/证据 section；
- 一至两跳 Link 展开、方向、截断、游标和 `completeForAuthorizedScope`；
- 搜索计数、自动完成、关联度数的防推断规则；
- 百万对象负载门。

**禁止**：M07 按名称合成 ID；M01 模型预览充当消费 API；M07/M02 复制 Object Type 定义。

### CR-M07-D：时序与空间读取合同

**目标**：建立 TimeSeriesRef/GeoRef 及查询语义。

**时序最小项**：系列身份、时间语义、native grain、单位、缺失分类、聚合/滚动/差分、阈值引用、事件引用、降采样证据和版本。

**空间最小项**：Geo Property、geometry member、type/CRS、有效时间、geometry/data version、图层读取、bbox/within/intersects、聚合/矢量瓦片和关系展开。

**禁止**：M07 插值成更细粒度、即时地理编码真值、定义 Metric/Rule 阈值或保存几何副本。

**需 Owner**：M01 语义、M02 数据/质量、平台安全、M07 呈现。

### CR-M07-E：Lens、Session、角色视图与深链

**目标**：登记 M07 自有资源及平台导航交换。

**最小范围**：

- LensDefinition revision 和 `draft/active/retired/needs_review`；
- ExplorationSession/QueryRun 的到期、废弃、历史与证据；
- RoleViewBinding 只收窄授权，不产生数据副本；
- opaque deep-link context，固定对象/时间/地图/筛选/返回位置；
- 打开/返回均重新鉴权并重读 C008/C017/C033；
- 禁止 URL 携带 token、隐藏值、成功状态、确认/待办/发布状态。

**依赖**：真实身份与权限服务、公共导航 Owner、安全审查。

### CR-M07-F：性能、限额与可观测性

**目标**：将百万对象、长时序和大量空间要素从“实现偏好”提升为可验证门。

**建议指标**：对象搜索 p95 <= 1.0s；360 摘要 p95 <= 1.5s；关系首跳 p95 <= 1.5s；时序/空间首屏 p95 <= 2.0s；本地交互 p95 <= 100ms。必须同时记录数据规模、权限选择性、缓存冷/热、p50/p95/p99、错误率、超时、资源峰值和版本。

**现有研究证据**：`performance/results.json` 在 Apple M4、Node v22.22.0 上对 100 万对象、100 万节点/1200 万边、100 万时序点和 50 万空间点的固定种子内存算法完成 10/10 门。其边界明确排除数据库、网络、权限、并发、序列化、排队、故障恢复和浏览器绘制；CR 不得把该结果改写为生产 SLO 已通过。

**必须明确**：分页/截断/降采样/瓦片上限、成本配额、取消、超时、回压、审计日志和监控 Owner。S005 小样本不得替代规模证据。

### CR-M07-G：与 M03/M04/M06 的交换边界

**目标**：只在有真实旅程时增加最小交换，不创造平行 BI/决策/报告资源。

**建议一期**：

- M03：可接收 ObjectRef/范围/返回位置，仍自行形成 C009/C010/C018；
- M04：仅导航；M07 不列为 C011 来源；
- M06：可保存/展示 M07 稳定深链引用，但正式卡片、布局、报告和发布仍归 M06。

若用户决定 M07 一期直接提交 Action，再单独扩展 C011 来源类型、幂等键、三道 C017 安全门和接收/拒绝回执；不能把该范围夹带在深链 CR 中。

## 5. 不建议提交的伪 CR

- “把 Object Explorer/Quiver/Map 复制进平台”：品牌和页面复制不是业务合同。
- “M07 读取所有 Published 数据”：Published 不自动授权，且 C008/C017/用途门仍必须成立。
- “Lens 保存一份角色数据”：形成副本并破坏撤权。
- “URL 带完整状态即可共享”：会泄露敏感筛选且不能替代鉴权。
- “S005 79 周数据已验证时序/空间/性能”：只能验证周时序状态；无正式 Published、无权威几何。规模算法证据来自独立合成夹具，不来自 S005，也不是生产端到端证据。
- “原型按钮可用即合同完成”：隔离适配器只能证明消费者行为。

## 6. 建议用户评审批次

1. **第一批：定位与 Owner**：U-M07-001—005，决定模块归属、对象/系列/空间 Owner。
2. **第二批：安全与导航**：U-M07-006—009，决定真实权限门、深链和分享/Action 边界。
3. **第三批：规模与场景**：U-M07-010—012，确认 SLO、S005 空间降级和正式基线。
4. 用户裁决后由总控拆分/合并上述 CR，分配正式编号并回写各 Owner；M07 研究分支不直接修改权威文档。
