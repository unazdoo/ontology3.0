# 权限、质量、版本与证据传播规则

> 状态：研究建议；不是权限实现证明或跨模块合同已生效结论
> 原则：每次读取重新判定，未知即关闭，历史不改写

## 1. 已确认事实与硬限制

| 轴 | 当前权威 Owner/合同 | 当前可复用 | 当前硬限制 |
|---|---|---|---|
| 权限 | 身份/权限平台；M01 定义可见性边界 | M07 可设计用途和角色视图的“只收窄”规则 | 当前一期仅单一演示账号，真实角色、对象/属性/关系负向和撤权证据未形成；原型只能模拟 |
| 语义版本 | M01 C004/C007 | 稳定资源 ID、精确 Published 版本、状态、有效时间和允许发现 Link | M07 尚非登记消费者；不得读取 Draft、按名称猜测或静默升级 |
| 权威组合 | M01 C008/T019 | 精确 `(Published, T007)`、T008、切换/回退证据和明确读取状态 | M07 不得自建指针、读取多个状态源或自动回退 |
| 数据质量 | M02 C017 | 版本绑定摘要、当前状态摘要、T007/T008、质量/新鲜度、影响范围和证据定位 | C017 当前消费者名单未正式加入 M07；不得复制质量真值或从数据明细反推 |
| 场景 | 平台 C033/C034 | C033 五字段、历史只读和定向重置；C034 精确快照引用 | Foundation/C034 只认 M01—M06；未 CR 前 M07 不得声称参与正式 Checkpoint |
| 证据 | 各 Owner | M07 可保存稳定 evidence locator 和查询 Run 引用 | locator 不等于内容访问；证据不可定位不能显示“已核验” |

## 2. 一次读取的固定上下文（建议）

所有 Lens 使用同一 `ReadContext`：

```text
subjectContextRef + purpose
+ C033(scenarioId, scenarioVersion, scenarioRunId, formedAt, status)
+ C007 exact Published version
+ C008 projection id/version/formedAt/readStatus
+ exact T007 + T008
+ C017 binding summary id/version/formedAt
+ C017 current summary id/version/formedAt
+ query formedAt
```

字段只是共同显示还不够；服务端必须证明它们互相绑定。任何分量缺失、类型错误、形成时间逆序、场景错配、版本错配、状态未知或读取失败，都不得产生正式业务结果。

## 3. 门禁顺序（建议）

### G0：请求与用途

- schema、query kind、参数、资源数量和 purpose 合法；
- 真实 `subjectContextRef` 可读取且未过期；
- C033 完整、active 或明确历史只读；
- 深链/Session 没有携带授权成功或业务成功状态。

失败：不访问业务数据，返回最小错误和审计引用。

### G1：Published 与权威组合

- C007 精确版本为允许消费的 Published 状态；
- 所有 Object Type/Property/Link 都属于该版本及获准发现范围；
- C008 是 M01 唯一投影，readStatus 明确，T019 指向同一 Published/T007；
- 无本地白名单、旧 localStorage、显示名称或静态默认组合参与判断。

失败：阻断查询；若只是历史版本仍可按 C034/Owner 合同定位，则只读历史并显著标记。

### G2：权限

- 依次判定模块访问、用途、对象类型、对象、属性、Link、证据内容访问；
- Lens/角色视图只作 intersection；
- 搜索索引、聚合计数、关联数、自动完成、地图簇和错误消息也必须经过同一授权；
- query service 使用调用者/受控服务用途身份，不使用 Lens 作者权限。

失败：按最小披露返回 `denied/redacted`；不得用 `null/0/empty` 泄露或伪装。

### G3：数据版本、质量与新鲜度

- C017 两类摘要均能定位，精确 T007/T008 与 C008 一致；
- 按对象、属性、关系、时间段和几何范围映射影响范围；
- 硬质量失败阻断受影响的新搜索结果、派生、阈值判断、图层和任何行动候选；
- `unknown`、摘要读取失败或影响范围无法确定时保守阻断相关范围；
- warning 可展示但必须携带原因、范围、时间和证据。

失败：不自行回退 T019；等待 M01 原子回退或新安全组合。

### G4：证据与结果形成

- 每个结果/区段携带可用的稳定 locator、Owner、精确版本和访问状态；
- locator 可定位但内容无权时显示“证据存在但当前不可访问”，不返回内容摘要；
- 证据必填的结果若不可定位，返回 `evidence_unavailable` 并阻断相应正式结论；
- 记录 QueryRun、服务端实际 ReadContext、授权 decisionRef、结果哈希和耗时。

### G5：返回前复核

长查询、分页、两跳、时序窗口和地图瓦片在返回前复核 C033、C008、C017 和授权上下文。任一变化，当前 Run 标记 `superseded/context_changed`；已产生的片段不能与新上下文合并。

## 4. 传播不是单一布尔值

### 4.1 每个字段/对象的状态

| 维度 | 允许值 | 禁止合并 |
|---|---|---|
| 适用性 | `applicable / not_applicable / unknown` | `not_applicable` 不能显示为无数据 |
| 访问 | `allowed / allowed_with_redactions / denied / unknown` | denied 不能显示为 null 或 0 |
| 数据存在 | `observed / valid_null / not_observed / source_missing` | not_observed 不能前值填充 |
| 质量 | `pass / warning / hard_block / unknown` | unknown 不能当 pass |
| 版本 | `exact / historical_exact / mismatch / unavailable` | mismatch 不能自动用 current |
| 证据 | `locatable_and_allowed / locatable_but_denied / missing / unknown` | locator 存在不能推出内容已核验 |

最终可呈现内容取这些轴的交集，不用一个 `available=true` 覆盖。

### 4.2 Lens 间传播

| 从/到 | 必须保持 | 可以改变 |
|---|---|---|
| 搜索 -> 360 | ObjectRef、Published/C008/C017/C033、权限用途 | 请求的属性 section |
| 360 -> 关系 | ObjectRef、获准 Link 范围和质量状态 | 展开跳数、布局 |
| 关系 -> 时序 | 选中 ObjectRef、版本和证据 | TimeSeriesRef、时间范围 |
| 时序 -> 空间 | 对象、时间范围、版本和权限 | GeoRef、viewport、图层呈现 |
| 任一 Lens -> 返回 | 稳定 route/context 和 ObjectRef | 对方模块重新读取后的当前状态 |

不得传播前一 Lens 的“已授权/质量通过/查询成功”作为下一 Lens 的门禁结果。

## 5. 角色视图与缓存

### 5.1 角色视图

角色视图有效范围为：

```text
底层身份授权 ∩ purpose policy ∩ RoleViewBinding 收窄 ∩ LensDefinition 收窄
```

- 不产生角色专属对象表、搜索索引副本、时序副本或空间图层副本；
- 不在 Lens 中维护角色成员；
- 共享 Lens 不转移作者权限；
- 角色变化后下次查询立即重判，已有 Session 标记需重新授权。

### 5.2 缓存

| 缓存 | 允许保存 | 必须绑定 | 失效条件 |
|---|---|---|---|
| 定义缓存 | C004/C007 最小发现元数据 | Published 版本、resourceId | 发布状态/版本变化 |
| 查询结果缓存 | 最小获权结果片段 | subject/purpose 的安全分区、C033、C008、C017、请求哈希 | 权限撤销、轮次/版本/质量变化、TTL |
| 布局缓存 | 坐标、面板、列宽 | Lens revision、ObjectRef 哈希 | 节点集合或 Lens 变化 |
| 深链上下文 | 稳定引用和筛选 | owner/access policy、到期时间 | 撤权、过期、显式删除 |

缓存键中不得只用对象 ID；不同用户/用途不得共享未重判的业务结果。撤权后即使上游暂不可用，也不能从旧缓存返回原值。

## 6. 质量传播细则

| 情形 | 搜索/360 | 关系 | 时序 | 空间 |
|---|---|---|---|---|
| 属性级 warning | 可显示值和警告 | 若不影响端点可继续 | 标记受影响点/范围 | 标记相关要素/弹层 |
| 属性级 hard block | 隐藏/阻断该值，保留原因 | 依赖该属性的筛选/标签阻断 | 受影响系列/点不参与派生和阈值 | 依赖该属性的样式/筛选阻断 |
| Link hard block | 可显示不依赖 Link 的 360 | 该 Link 展开阻断 | 事件定位若依赖 Link 则阻断 | 关系展开阻断 |
| 时间范围部分缺失 | 显示范围状态 | 不适用或按关系自身状态 | 断线并标明 source_missing | 时间过滤后缺口显式显示 |
| 几何 hard block | 对象其他信息可显示 | 非空间关系可显示 | 非几何系列可显示 | 不返回原几何/瓦片 |
| 影响范围未知 | 相关 section 保守阻断 | 保守阻断 | 保守阻断 | 保守阻断 |

M07 只解释 C017 已给出的状态、范围、原因和恢复建议，不定义质量阈值、不修数据、不把 UI 严重级别写回 M02。

## 7. 历史、回退与快照

1. 历史 QueryRun 保留原 Published、T007/T008、C017、C033 和授权 decisionRef；不得随当前状态原地改写。
2. 当前权威采用后硬质量失败时，历史结果可追溯但追加当前警告；不得用于新派生、刷新或 Action。
3. M07 不切换或回退 T019。只有 M01 按 C008 受控原子回退；M07 新会话重新读取。
4. C034 历史查看保持原 `scenarioRunId`；恢复/回归/迁移使用新轮次。M07 正式参与 C034 前必须先经 CR 扩展 MODULE_IDS 和导出/恢复接口。
5. Checkpoint 只保存 M07 Lens/Session/QueryRun 的稳定引用与校验回执，不复制对象值、C017 内容或 M01/M02 真值。

## 8. Action、问数和报告边界

| 相邻模块 | 允许传播 | 禁止传播 |
|---|---|---|
| M03 智能问数 | 稳定 ObjectRef、范围和返回深链（需新合同）；由 M03 自行装配 C009/C010 上下文 | M07 不生成自然语言正式答案、不复制 C018、不把图形筛选当问数成功 |
| M04 决策中心 | 只读稳定上下文和返回位置；未来若获 CR 可作为 C011 来源提交标准请求 | 当前 C011 来源没有 M07；不得直接确认、执行、创建待办或携带成功状态 |
| M06 报告中心/仪表盘 | 只读 ObjectRef、Lens 深链和证据定位；由 M06 决定正式卡片/报告 | M07 不保存布局、发布、正式报告或仪表盘生命周期，不把探索视图称正式经营视图 |

## 9. 必须通过的负向测试

1. 无 subject、伪造角色、用途不符、对象有权但属性/Link 无权、证据 locator 有权但内容无权。
2. 搜索计数、自动完成、关系度数、地图簇在无权范围内不泄露数量。
3. C008 缺失/empty/损坏/错生产者/错轮次；C017 缺失/未知/硬失败/证据缺失/影响范围未知。
4. Published 已替代、资源同名、ObjectRef 标题变化、分页期间版本变化。
5. 撤权后旧 Session、深链、浏览器返回和缓存均不泄露旧值。
6. S005 2025-10-20 缺表不填 0；管理人缺身份、发行人名称级候选和空间缺失均关闭。
7. 当前权威硬失败时 M07 不自动回退，不允许新差分、阈值定位或 Action。

由于当前权限只能模拟，模拟用例通过只能关闭交互逻辑，不能关闭第 1、2、5 项真实安全门。正式评审需要真实身份服务的正负证据与安全审查。
