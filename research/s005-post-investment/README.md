## 一期最小化原则

一期只研究并验证支撑投后判断的最小闭环：

1. 产品、管理人、发行人、投资持仓和快照的稳定身份；
2. 周快照接入、版本化、质量和历史重现；
3. 产品分类、同类组和比较基准；
4. 可由现有资料真实计算的收益、风险、集中度和期限指标；
5. 数据不足时的部分评价和诚实降级；
6. 评价结果、证据链、人工复核和建议行动边界；
7. 选择少量真实产品完成历史回放。

一期暂不默认建设自动交易、复杂组合优化、实时行情、全市场排名、任意脚本策略平台或生产级数字孪生。它们必须经过单独裁决。
