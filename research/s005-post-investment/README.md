## 一期最小化原则

一期只研究并验证支撑投后判断的最小闭环，投资范围限定为利率债、短期纯债基金、中长期纯债基金、混合一级债基和混合二级债基：

1. 产品、管理人、发行人、投资持仓和快照的稳定身份；
2. 周快照接入、版本化、质量和历史重现；
3. 产品分类、同类组和比较基准；
4. 可由 Wind 分类、日 NAV 和交易资料真实计算的收益、风险、集中度和期限指标；
5. 数据不足时的部分评价和诚实降级；
6. 评价结果、证据链、人工复核和建议行动边界；
7. 选择少量真实产品完成历史回放。

本轮新增要求将“市场同类基金池横评、入池选择能力、持续准入合规、交易择时与日常/事后评价”纳入一期研究和只读驾驶舱最低闭环；一期不设置多级权限/安全/自动阻断门，只展示事实状态和证据。正式全市场榜单、实时行情、自动交易、复杂组合优化、任意脚本策略平台和生产级数字孪生仍需单独裁决。

## 允许与禁止

允许：

- 在本工作区创建研究文档、只读解析脚本、字段审计、脱敏夹具和测试；
- 对周快照做结构一致性、稳定键、变化轨迹和可复现性验证；
- 对评价指标、权重、范围事实状态和等级规则做实验与回放；
- 提出跨模块合同和 CR 建议；
- 建立隔离研究原型，但必须标记为研究状态且使用独立命名空间。

禁止：

- 修改平台总控台账、六模块主文档、当前组合原型或冻结版本；
- 把研究推荐自动升级为用户裁决；
- 把试验指标、权重、阈值、模型或结果登记为 Published；
- 创建正式 T019、Action Request、提醒、审批、待办或交易指令；
- 用周快照推断不存在的日内或每日净值事实；
- 用 LLM 替代正式计算或作为业务数据源。

## 进入完整建设的门

必须同时满足：

- 公共产品来源基线已正式冻结并完成重基线；
- 产品类型、评价目的、比较基准和评价频率已确认；
- 数据字段、稳定键、快照频率和缺失策略已确认；
- 指标公式、范围事实状态、等级规则和最低历史长度已确认；
- M01至M08 Owner 和跨模块合同完成总控裁决；
- 真实历史回放证明评价结果可解释、可复算且具备区分度；
- 平台总控明确授权 S005 进入完整建设。

启动时使用同目录的 [START-PROMPT.md](./START-PROMPT.md)。
