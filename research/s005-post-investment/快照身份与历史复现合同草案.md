# S005 快照身份与历史复现合同草案

> 状态：研究候选合同；不构成 C001-C003/C017/C033/C034 的正式扩展
> 命名空间：`ofw.s005.research.v1`

## 1. 合同目的

本草案只回答三件事：某份快照是否原样可定位、同一候选对象能否跨期关联、给定同一输入能否得到同一研究结果。它不创建正式数据资产、本体对象、评价模型、Action 或 T019。

## 2. 三层身份

### 2.1 来源快照身份

候选键：`source_path + file_sha256`。同名但哈希不同必须形成新来源版本；哈希相同但路径或发现时间不同只登记新的发现证据，不重复生成业务快照。

最小字段：

- `source_file_name`、`source_file_sha256`、`size_bytes`；
- `snapshot_date_candidate`、日期解析规则、T008 待确认状态；
- 工作表清单、表结构签名、字段签名、记录数；
- 解析器名称/版本、解析时间、成功/失败及原因；
- 敏感等级、访问上下文、证据定位。

### 2.2 快照行证据身份

候选键：`source_file_sha256 + sheet_role + source_row_ordinal`。它只定位源证据，不作为产品、管理人、发行人或持仓的稳定业务身份；源文件一旦修订，行证据必须形成新版本。

### 2.3 业务对象候选身份

| 对象 | 当前候选 | 置信度 | 冲突处理 |
|---|---|---|---|
| 产品/份额 | 规范化证券代码 | 较强候选 | 代码缺失、复用、份额变更、合并或名称别名变化时进入人工裁决 |
| 管理人 | 无 | 不可用 | 必须补管理人统一代码和法定名称；禁止从产品名称拆词推断 |
| 发行人 | 规范化名称 | 中等、名称级 | 必须补统一社会信用代码、LEI 或内部主数据 ID；同名冲突不得自动合并 |
| 产品持仓 | 产品候选 ID + 观察时点 | 较强候选 | 只表示时点持有，不推导申赎事件 |
| 债券持仓 | 债券名称 + 观察时点 | 中等、名称级 | 必须补债券代码/ISIN、发行人 ID；名称变化进入人工裁决 |

研究伪名算法为 `SHA-256(namespace|domain|normalized_source_key)` 截取 16 位大写十六进制，仅用于隔离输出。伪名稳定不表示源键已获业务确认。

## 3. 跨期关联状态

每次匹配必须保留以下状态之一：

- `EXACT_CANDIDATE_KEY`：同一规范化候选键；
- `ALIAS_REVIEW_REQUIRED`：代码一致但名称变体变化；
- `MASTER_DATA_REQUIRED`：仅名称可用，需主数据；
- `AMBIGUOUS`：一个源键对应多个现实对象或反向冲突；
- `UNMATCHED`：无法关联；
- `MANUALLY_CONFIRMED` / `MANUALLY_REJECTED`：业务 Owner 的版本化裁决。

禁止规则：不以行号、显示名称、当前持仓数量或“最近出现”静默消歧；不把产品退出快照自动解释为赎回；不把新出现自动解释为新申购。

## 4. 历史复现输入锁定

一次研究回放必须固定：

1. 源文件清单及 79 个 SHA-256；
2. 解析器、脚本提交和字段映射版本；
3. 身份映射版本及人工裁决证据；
4. 评价时点和当时可得数据截点；
5. 公式/参数/分类/基准/同类组版本；
6. 功能开关，尤其是外发、Action、通知、审批、待办和交易一律关闭；
7. 输出摘要哈希、失败记录和执行环境摘要。

同一输入重跑必须得到相同结构、候选身份覆盖、质量状态和研究指标。源修订、映射修订或参数修订必须形成新 run，不能覆盖旧结果。

## 5. 结构异常处理

- 2025-10-20 缺少两张表，标记 `PARTIAL_SNAPSHOT_MISSING_SHEETS`；不沿用 10 月 17 日值，也不使用 10 月 24 日回填。
- 未命名列标记 `UNDEFINED_FIELD`；`#NAME?` 标记 `SOURCE_FORMULA_ERROR`。
- 重复产品候选键标记 `DUPLICATE_KEY_WITHIN_SNAPSHOT` 并阻断该对象当期计算。
- 日期不规则只记录实际观察间隔；不得将周期间隔重采样成日频。
- 核心字段空值与数值 0 分开处理；未知值不得按 0。

## 6. 与平台合同的候选映射

| 研究资源 | 未来候选 Owner/合同 | 当前边界 |
|---|---|---|
| 来源与文件快照 | M02 / C001-C003 | 目前仅研究清单，不是 T001/T002/T007 |
| 数据可信度摘要 | M02 / C017 | 只输出覆盖、质量和缺口，不含正式业务结论 |
| 对象稳定身份和语义 | M01 + 业务 Owner | M02 保存匹配证据；研究层不创建 Published Object |
| 场景三元身份 | 平台公共层 / C033 | 研究命名空间不可自动升格为正式场景 |
| 回放/恢复清单 | 平台公共层 / C034，模块各自导出 | 本草案只验证研究输入锁定和无副作用重跑 |

## 7. 验收候选

- 79/79 文件哈希、结构和记录数可重算；
- 结构异常被准确识别且不被补值；
- 原始敏感身份不进入研究制品；
- 同一源清单重跑输出一致；
- 至少一个名称别名、一个缺表、一个公式错误和一个未知字段能诚实降级；
- 回放全程不产生 Published 资源、T019、Action、提醒、审批、待办或交易副作用。
