# S005 投后评价研究驾驶舱原型

## 定位

这是 `ofw.s005.research.v1` 的研究型、只读、中文高密度驾驶舱，沿用 v1.1.0 冻结实施参考的模块栏、浅色数据工作区、状态徽标、表格、证据抽屉和 Lucide 图标语汇。它不是 v1.1.0 的修改，也不写入组合工作树。

## 视觉系统

- 方向：金融运营的精密控制台，优先扫描、对比和证据回链。
- 字体：`-apple-system`、`SF Pro Text`、`PingFang SC`、`Noto Sans SC`。
- 色彩：v1.1.0 的深蓝主色；青/绿表示已核验；琥珀表示复核；红表示硬风险；灰表示未知。
- 图表：`chart-stage.js` + D3，时间序列支持缩放、tooltip、SVG/PNG 研究导出；缺口显示为断点。
- 数据：`data.js` 是研究夹具，所有数值都明确标注为待 Wind/内部交易数据替换。

## 交互

- 五个视图：全周期总览、全市场与入池、准入合规、池内选择、交易与风险。
- 评价方法、数据源状态、v1.1.0 模块关联和合规证据通过只读抽屉查看。

## 三版本比较

- `variants.html?variant=a`：版本 A「运营总览型」，指标密度最高，适合日常管理扫读。
- `variants.html?variant=b`：版本 B「流程工作台型」，按来源、分类、合规、选择、交易、复盘顺序推进。
- `variants.html?variant=c`：版本 C「研究分析型」，图表和公式说明占比最高，适合投研复盘。
- 不提供 Action Request、提醒、审批、待办、交易下单或生产发布按钮。

## 运行

```bash
python3 -m http.server 4355 --bind 127.0.0.1 --directory research/s005-post-investment/prototype
```

打开 `http://127.0.0.1:4355/index.html`。正式数据接入时，只替换 `data.js` 的研究夹具并保留数据源/公式/版本字段，不改变页面合同。

## 全链路增量源

用于整体走查的 S005 增量源位于 `full-chain/`。总装时将它与只读 v1.1.0 冻结底座物化后，入口为 `full-chain/index.html`。它把 M02 → M01 → 持续合规 → 市场同类 → 池内选择 → 交易与风险 → M06 串成一个可运行、可重置的 `S005-v1` 研究轮次；运行状态仅写入隔离命名空间。冻结底座、`BASELINE-*` 副本和本机符号链接不在本归档中重复保存。
