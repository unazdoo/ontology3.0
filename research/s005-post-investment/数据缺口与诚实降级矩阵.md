# S005 数据缺口与诚实降级矩阵

> 状态：研究建议；可计算性指当前资料的真实能力，不代表指标已获业务审批

## 1. 可真实计算或重现

| 指标/事实 | 当前能力 | 数据来源 | 限制与输出标签 |
|---|---|---|---|
| 快照文件数、日期、哈希、大小、表结构、记录数 | 可精确重现 | 79 个原始 XLSX | `SOURCE_AUDIT_FACT` |
| 产品跨期出现、首次/末次出现、覆盖率、名称别名数 | 可计算 | 证券代码、名称、快照日期 | 候选身份；不等于产品存续期 |
| 快照时点持仓数量、投资金额、当前市值 | 可读取并按产品/组合汇总 | 投资项目每周简报 | 时点事实；需确认 T008、币种、成本/估值口径 |
| 快照时点浮动盈亏、来源累计投资收益、来源累计已实现盈亏 | 可读取和勾稽实验 | 投资项目每周简报 | 保持源字段名；未核验前不重命名为正式会计指标 |
| 单产品市值/成本集中度、分类占比 | 条件可算 | 当前市值/投资金额、分类 | 分母和分类版本必须固定；2025-10-20 缺表不影响产品简报本身 |
| 相邻快照数值差额 | 只能作诊断性差额 | 离散周快照 | 输出 `OBSERVED_SNAPSHOT_DELTA`；不得称交易、现金流或收益 |
| 来源债券净价差、累计收益率、已收利息 | 可读取或条件复核 | 债券交易风险表 | 仅 1 条/期；公式、日期、现金流口径待确认 |
| 来源期限、单户集中度、固收投资占比 | 可读取并作时点趋势 | 固收业务风险表 | 2025-10-20 整表缺失；债券/发行人身份仅名称候选 |
| 投资限额实际值和来源状态 | 可按期重现 | 投资风险限额表 | 来源阈值/状态，不自动升级为 S005 Rule；2025-10-20 缺失 |
| 15 只产品的结构历史回放 | 可执行 | 脱敏候选 + 79 期清单 | 证明可追踪性，不证明评价质量 |

## 2. 当前不能真实计算

| 目标指标 | 当前为何不能 | 必需补充 | 降级方式 |
|---|---|---|---|
| 产品 TWR、年化 TWR | 无完整复权日净值、分红/拆分/份额事件 | 份额类别日净值、累计净值、收益分配和修订版本 | 不用现价或本公司盈亏替代；产品表现域不可算 |
| 基准超额、同类中位数/前三分之一、信息比率、跟踪误差 | 无版本化基准日总回报序列、Wind 分类和点时同类池 | 每类产品基准、日总回报、Wind `fund_type`、评价日存续/退出状态和映射版本 | 只报告绝对来源事实，状态至少为部分评价 |
| 同类排名、分位数、星级 | 无同口径点时同类基金池和分类历史 | 同类组成员、历史分类、样本规模、费用/存续过滤 | 只做描述性中位数/前三分之一比较，不生成外部等级 |
| 日频波动、下行波动、最大回撤、VaR | 周期间断价格不是日频复权净值 | 连续日净值/行情和交易日历 | 不年化周快照为“日频”结果 |
| 财务公司 MWR/XIRR | 无逐笔申赎、买卖、分红、利息、费用、税费和日期 | 完整现金流事件账、期初期末估值和勾稽 | 只展示来源会计快照；不反推现金流 |
| 已实现/未实现/现金收益的完整桥接 | 字段为时点/年累计候选，缺交易和现金流明细 | 交易、现金流、会计分录、估值和费用 | 只显示源值及差异，不能形成完整归因 |
| 基金穿透久期、期限、信用、行业和发行人集中度 | 无基金底层持仓及披露时点 | 穿透持仓、证券主数据、披露版本 | 仅评价台账已有层级，标注 `NO_LOOK_THROUGH` |
| 评级分布和评级迁移 | 无评级机构、评级值、生效日和历史事件 | 证券/发行人评级事件、机构、展望和日期 | 不从名称或当前评级推历史迁移 |
| 流动性评分 | 无成交、买卖价差、成交量、赎回条款、冲击成本 | 市场流动性、产品申赎和限制事件 | 只显示可见赎回/限额事实，风险灯为灰或基于已确认事件 |
| 管理人质量 | 管理人身份字段缺失，且无人员/治理/披露事件 | 管理人主数据、基金经理、审计/托管/披露和重大事件 | 管理运行域不评分 |
| 风格漂移 | 缺合同基准、持续持仓/因子暴露 | 合同约束、分类历史、穿透持仓或可复算风格暴露 | 不从名称变化推断 |
| 市场同类基金池入池选择差异 | 无评价日点时基金池、清算/合并状态和历史分类 | Wind 全量导出、分类/基准版本、历史状态 | 只做研究夹具，不生成正式全市场排名 |
| 持续准入合规 | 无管理人主数据、处罚/监管措施/自律处分事件映射和合同穿透 | 中基协/证监会/管理人公告、主体统一代码、基金合同和持仓 | `需复核` / `无法判断`，不等于符合 |
| 池内选中 vs 未选选择能力 | 无交易前决策日志、可执行池、未选原因和前瞻窗口 | 决策账、额度/流动性/现金状态、订单引用、T+窗口结果 | 不把未选直接当负例，不宣称 alpha |
| 交易择时/执行滑点 | 无逐笔订单、有效 NAV/成交价、费用、结算和同时点参考价 | 内部交易/现金流/费用、Wind NAV、中债/CFETS/交易所 | 无日频/交易时间则不可评价 |
| 操作风险 | 无订单—成交—结算—估值—总账链路和迟报/修订日志 | 系统日志、对账、公告、人工覆盖记录 | 独立操作风险灯，不由收益抵销 |
| 正式综合评分、等级和风险灯 | 权重、状态语义及 Owner 未裁决 | 业务裁决、版本化参数、回放验证 | 一期不设多级门禁；只做维度结果、事实状态和风险灯 |

## 3. 缺失处理矩阵

| 缺失/异常 | 不允许 | 必须行为 | 评价影响 |
|---|---|---|---|
| 核心身份不稳定 | 按名称或相邻行猜测 | 标记冲突并等待主数据/人工裁决 | 无法评价 |
| 产品日净值缺失 | 用持仓市值变化替代 TWR | 产品表现域不可算 | 部分或无法评价 |
| 现金流缺失 | 从持仓差额反推 MWR | 实际投资结果域仅显示会计快照 | 部分评价 |
| 基准缺失 | 默认使用单一指数 | 显示无基准及待裁决映射 | 不算超额/信息比率 |
| 同类组缺失或样本太小 | 输出排名 | 只做绝对/基准比较 | 不输出同类等级 |
| 穿透持仓缺失 | 宣称完整固定收益风险 | 仅评台账可见层级 | 风险域部分评价、置信度下降 |
| 2025-10-20 缺两表 | 沿用前值/后值 | 保留整表缺失 | 对相关域标灰/部分 |
| `#NAME?` 或未命名列 | 自动修复或猜字段名 | 保留源错误，排除计算 | 数据质量灰/黄候选 |
| 观察期短于最低门 | 年化并排名 | 展示当前事实和实际观察长度 | 观察期不足 |
| 数据过期 | 当作当前状态 | 显示截至时间、时效状态和恢复建议 | 降置信度或无法评价 |

## 4. 四种评价状态候选

| 状态 | 候选定义 | 允许输出 |
|---|---|---|
| 完整评价 | 所有适用核心域满足身份、历史、频率、完整性、勾稽、基准/同类和范围事实可判断要求 | 全部适用指标、维度结果、独立风险灯、置信度和结论 |
| 部分评价 | 至少一个核心域可真实计算，但其他适用域缺失 | 已验证指标、覆盖率、缺失清单和受限结论；不伪造总分 |
| 观察期不足 | 身份和当前事实有效，但历史短于经批准最低长度 | 当前持仓、损益、风险事实；不输出长期表现评分 |
| 无法评价 | 核心身份失效、估值/现金流无法勾稽、数据过期或没有可靠核心域 | 失败原因、待补数据和人工复核提示；不输出方向性评价 |

## 5. 按日补充要求

1. 产品/份额类别日净值、累计净值、分红和估值发布状态。
2. 基准日总回报、基准定义和版本化产品映射。
3. 财务公司逐笔申购、赎回、买卖、分红、利息、费用、税费及业务日期。
4. 每日持仓、成本、市值、应计利息、已实现/未实现损益和勾稽字段。
5. 债券代码/ISIN、发行人 ID、条款、票息、到期/回售/赎回日、估值价和价格来源。
6. 评级机构、评级、展望、生效/失效时间和迁移事件。
7. 管理人、基金经理、托管人、产品合同、披露计划/实际披露和重大事件。
8. 基金穿透持仓按真实披露频率接入，绝不制造日频穿透事实。

每条日数据至少携带业务日期、事件时间、入库时间、来源、源记录键、修订序号、有效区间和质量状态。节假日/未披露必须显式标记，不以前值填充伪造观测。
