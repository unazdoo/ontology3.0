五、跨模块边界

1. 数据工程拥有数据源、原始快照、管道、质量检查和数据资产版本；本体只选择、映射和消费。

3. 决策中心承接 Action 请求、提醒、人工确认和待办的运行过程；本体只设计 Action Type，具体 Owner 以总控裁决为准。
4. Agent 应用拥有报告/洞察 Agent 的配置与运行；本体提供获准语义资源。
5. 报告中心只引用 Published 对象、Metric、Rule 结果和 Action 入口，不复制业务口径。
